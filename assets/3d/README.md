# 3D 桌宠模型替换说明

本目录用于放置自定义 3D 骨骼动画模型，替代内置的程序化人形。

## 快速替换

1. 准备一个带骨骼动画的模型文件（`.glb` 或 `.gltf`）。
2. 重命名为 `pet.glb`，放到本目录：`assets/3d/pet.glb`
3. 重启应用即可。若文件不存在，应用会自动降级到内置程序化人形，不会白屏。

## 格式要求

- 推荐 `.glb`（单文件，内嵌贴图），最省事。
- 模型必须包含 **骨骼（Skin）** 和至少一个动画剪辑。
- 面向 Z 轴正方向（面向摄像机），否则人物会背对镜头。
- 模型尺寸建议总高约 2 个单位，重心在原点附近；过大或过小可在 HTML 里调 `model.scale`。

## 情绪动画剪辑命名建议

前端会按情绪名匹配动画剪辑（忽略大小写）。建议在建模软件里把动画剪辑命名为：

| 情绪     | 建议剪辑名 | 说明               |
|----------|-----------|--------------------|
| idle     | `Idle`    | 待机场景循环        |
| happy    | `Wave`    | 开心挥手           |
| confused | `Confused`| 疑惑歪头           |
| angry    | `Angry`   | 生气               |
| sad      | `Sad`     | 难过               |
| shy      | `Shy`     | 害羞               |

匹配规则：前端会把情绪名映射到上表，找不到对应剪辑时自动播放第一个动画剪辑作为兜底。

## 注意

- 本目录默认不放模型文件（仓库体积考虑）。
- `file://` 协议下加载本地 `.glb` 需要相对路径 `assets/3d/pet.glb`，前端已写死。
- 如果模型带外部贴图（`.gltf` + `.bin` + 贴图），请保持同目录结构并改前端加载路径。
