## 二、做完的功能清单

### 1. WebSocket 事件联动（成品级）
- **兼容两种消息格式**：
  - 旧格式 `{type, data}` → 正常解析
  - 新格式 `{event, text, emotion, relationship_stage, data}` → 正常解析
- **事件处理**：
  - `thinking` → 状态机切 THINKING，气泡显示 text（没有 text 就显示 "..."）
  - `speaking` → 状态机切 SPEAKING，气泡显示 text（4秒自动消失），触发口型动画
  - `emotion` → 更新情绪数值；附带 emotion 字段时切表情（happy→开心, surprised→惊讶, angry→惊讶, shy→开心, neutral→回 idle）
  - `hello` → 记录连接成功，打日志
  - `relationship_stage` → 顶部弹出粉色标签显示关系阶段
  - `action` → 旧格式动作事件，正常兼容

### 2. 口型同步（自然说话）
- SPEAKING 状态下嘴巴张合**不再是死板正弦波**：
  - 每 0.2~0.5 秒随机切换口型模式：快说（高频大幅）/ 慢说（低频小幅）/ 停顿（嘴微张不动）
  - 用正弦波 + 二次谐波叠加，再加随机抖动，更接近真人说话节奏
  - Live2D 模型走 `MouthOpen` 参数，占位角色走同一 `setMouthOpen()` 接口

### 3. 设置面板
- 托盘菜单点"设置"→ 弹出毛玻璃深色面板（260px 宽，居中叠加）
- 可调项：
  - **桌宠大小**：滑块 0.08~0.30，实时调整模型 scale
  - **音量**：滑块 0~1（存设置，音频后续接）
  - **窗口置顶**：开关，实时调用 setAlwaysOnTop
  - **开机启动**：开关，存设置
  - **角色切换**：下拉选 Haru / 小团（占位），切换后自动重载页面
- 点关闭按钮或点面板外部 → 关闭面板
- 面板出现/消失有淡入淡出动画

### 4. 关系阶段标签
- 窗口顶部居中一个粉色半透明圆角小标签
- 收到 `relationship_stage` 时显示 "💕 暧昧期" 之类的文字
- 3 秒后自动淡出消失
- 毛玻璃效果，不挡交互

### 5. 丰富 idle 行为
- **眨眼 / 呼吸**：原有保留
- **偶尔歪头**：随机每 ~12 秒触发一次，左右 ±4 度，1 秒歪过去、1 秒恢复
- **轻微左右晃动**：持续的小幅左右摇摆（振幅 3px）
- **自动睡眠**：连续 60 秒无交互 → 进入 SLEEPING 状态（闭眼 + "Zzz..." 气泡）
- **眼神回正**：鼠标 3 秒不动，角色眼神逐渐回到正前方

## 三、完整链路测试方法

### 前置条件
1. LoveAI 主程序已启动，并在端口 9876 跑了 WebSocket 服务端
2. Electron 桌宠已启动（`npm start` 或打包后的 exe）

### 测试步骤
```
1. 启动 LoveAI 主程序
2. 启动 Electron 桌宠
3. 打开桌宠的开发者工具（Ctrl+Shift+I），看 Console 日志
4. 在 LoveAI 里触发一次"分析聊天记录"操作
5. 观察桌宠：
   - ✅ 思考阶段：桌宠切思考表情，气泡显示"正在分析..."
   - ✅ 说话阶段：桌宠嘴巴自然张合（不是死板的），气泡显示回复文字
   - ✅ 如果推送了 emotion:happy：桌宠切开心表情
   - ✅ 如果推送了 relationship_stage:暧昧期：顶部弹出粉色"💕 暧昧期"标签
6. 右键托盘图标 → 点"设置"
   - ✅ 弹出设置面板
   - ✅ 拖"大小"滑块 → 桌宠实时变大变小
   - ✅ 开"窗口置顶" → 窗口保持最前
   - ✅ 切换角色下拉 → 页面重载，角色换成小团
   - ✅ 点面板外部 → 面板关闭
7. 不碰桌宠 60 秒 → 桌宠闭眼睡觉，气泡显示 Zzz...
8. 点一下桌宠 → 醒来，随机台词
```

### 手动测试 WS 消息（不启动 LoveAI 也能测）
在桌宠的开发者工具 Console 里粘贴：
```js
// 模拟 thinking
wsClient.send(JSON.stringify({event:'thinking', text:'正在分析聊天记录...', emotion:'neutral'}))

// 模拟 speaking
wsClient.send(JSON.stringify({event:'speaking', text:'分析完了哦~她好像对你有意思！', emotion:'happy', relationship_stage:'暧昧期'}))

// 模拟 emotion
wsClient.send(JSON.stringify({event:'emotion', data:{affection:75}}))

// 模拟 hello
wsClient.send(JSON.stringify({event:'hello', data:{version:'1.0', status:'connected'}}))
```
> 注意：桌宠是 WS **客户端**，只能接收服务端推送，不能主动发消息给服务端。上面的 `wsClient.send` 只是往已连接的 WS 连接发消息——需要 LoveAI 服务端那边能收到并响应。如果 LoveAI 没启动，直接用下面的方法在浏览器里模拟：

在 Console 里直接调内部函数：
```js
// 直接触发 thinking（不经过 WS）
// 由于是 ES module，内部变量不暴露到 window，所以这个方法在 DevTools 里用不了。
// 正确测试方式：用 Python 或 Node 起一个假 WS 服务端在 9876 端口，然后推送消息。
```

**快速假服务端测试脚本**（保存为 `fake-ws-server.js` 运行）：
```js
const WebSocket = require('ws');
const wss = new WebSocket.Server({ port: 9876 });
wss.on('connection', (ws) => {
  console.log('桌宠已连接');
  // 1秒后推 thinking
  setTimeout(() => ws.send(JSON.stringify({event:'thinking', text:'正在分析聊天记录...', emotion:'neutral'})), 1000);
  // 4秒后推 speaking
  setTimeout(() => ws.send(JSON.stringify({event:'speaking', text:'分析完了哦~她今天好像心情不错！', emotion:'happy', relationship_stage:'暧昧期'})), 5000);
});
```
运行：`node fake-ws-server.js`，然后启动桌宠就能看到完整联动。

## 四、怎么启动、怎么用

### 开发模式启动
```bash
cd desktop-pet-electron
npm start
```

### 打包后使用
```bash
# 打包好的 exe 在 dist/win-unpacked/LoveAIPet.exe
# 双击运行即可
```

### 日常使用
- 桌宠出现在屏幕角落，可拖拽移动
- **左键点一下** → 随机台词 + 表情
- **右键托盘图标**：
  - 显示/隐藏桌宠
  - 设置 → 弹出设置面板
  - 切换角色
  - 退出
- **设置面板里**：调大小、音量、置顶、开机启动、换角色
