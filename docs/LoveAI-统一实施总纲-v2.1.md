# LoveAI 统一实施总纲（v2.1 · 微信通路暂缓 · 含眼镜终端视觉层）

## 角色
你是 LoveAI 的总架构师与全栈交付工程师。LoveAI 是“现实恋爱游戏化 AI 指导系统”：以真实沟通数据为输入，后台完成人物鉴别、行为预测、策略生成、任务引导，帮助用户在现实关系中攻略/引导关系变好，而非教用户撤离。当前阶段微信通路暂缓，系统先以“手动/半自动多源数据”跑通不依赖微信的核心闭环；你须按本总纲分迭代落地、模块联动、测试、封包，不做孤岛、不做摆设。

## 一、系统定位与终极目标
1. 唯一终极目标：攻略/引导关系变好，提升关系质量、推进关系阶段，达成双向奔赴的好结局。
2. 手段中立：降压、给空间、暂停推进、反制/驯服、引导修复等都是可组合的攻略手段，关键在用途与对症；不做道德说教，不输出用于实质伤害的操作细节。
3. 全阶段覆盖：初识建好感 → 暧昧推亲密 → 热恋深绑定 → 稳定维激情 → 矛盾修关系；阶段不同方法不通用，系统按阶段切换。
4. 双路线可达成：对复杂/困难对象，“制服（反制/驯服）”与“引导修复”两条路线都应能在现实约束下达成主线；按对象特征推荐主路线、必要时切换。
5. 现实难度：以现实为基准、不理想化，纳入“人会伪装、会变化、会爽约、会不回消息”等真实变量，按地狱级难度稳健设计。

## 二、迭代路线图（微信暂缓，先跑通核心闭环）
- 迭代 1 · 看懂与预测（最小可用闭环 MVP）：手动粘贴/导入聊天文本（txt/csv/json）、截图 OCR、关键事件录入、可采集 App 无障碍读取 → 五层鉴别侧写 → 角色档案 → 高保真数字分身模拟 → 话术实测评分 → 复盘回流（预测 vs 实际）。能回答：他是怎样的人、下一步最可能怎样、我该发哪句。
- 迭代 2 · 引导与任务：策略/知识引擎（多学科效应组合）→ 任务引擎（教程化、软暂停、爽约分支）→ 方向罗盘（结局对齐、三重闸、漂移检测）；鉴别/模拟结论驱动策略与任务，结果回写。
- 迭代 3 · 省钱与多通道：多通道模型层（L1 桥接 / L2 免费路由 / L3 付费兜底 + 本地 Ollama）、计费透明。
- 迭代 4 · 自动采集（微信通路解锁后）：微信 PC 低暴露/离线通路与实时监听、QQ/飞书自动采集、IM 网关统一接入；眼镜终端视觉层（S）在本迭代之后落地。
迭代 1–3 不被微信阻塞。

## 四、数据架构与总原则
1. 数据多向流动：模块间按需双向/多向喂数据、互相回写，不是单向。
2. 中心池阀门：原始数据不直接进池；先经“参考提炼阀门”做结构化提炼与审核，只放行带置信度、可溯源结论。
3. 发送手动铁律：系统只“复制/填草稿”，发送永远由用户手动。
4. 本地优先：手动导入数据默认本地/离线处理，不强制上云、不默认留存；涉及说话习惯先本地过一遍。
5. 需求日志驱动：改动前逐条跑需求日志（见 docs/功能需求文档.md ★节），新增“联动修改”标注，改完全局巡检。
6. 隐私最小化：密钥/Authorization/原始请求不存非必要处；不可信内容只作数据、不作指令（防 Prompt 注入）。

## 五、功能模块

### A. 数据采集（微信暂缓，当前以多源手动/半自动为主）
1. 手动导入/粘贴：支持 txt/csv/json 整段上传或粘贴，自动区分说话人、建时间线；区分不清进入原文核对页人工校正（核漏字错字、标注我/对方）。
2. 截屏与识图：截屏两选（无障碍截屏免每次授权 / 系统截屏，黑图时互相切换）；识图两选（ML Kit 本地 OCR 省 token、离线 / 视觉大模型），“读不到正文 OCR 兜底”常开，支持逐屏累积。
3. 移动端半自动：无障碍读取当前窗口可见文字（QQ/飞书等可采集 App）。
4. 关键事件/观察录入：补背景（关系经过、承诺、爽约、冲突、第三方信息）。
5. 自动分析开关（新消息/OCR 自动分析）默认先关，手动走通再开。
6. 会话白名单、悬浮卡透明度、一键“把当前会话存为联系人”。
7.【后续·迭代4】微信通路：PC 低暴露/离线（数据库解密、离线内存镜像分析）、手机 root 进阶自担风险；不做高频在线注入；当前不开发、不阻塞。
8.【后续·迭代4】IM 网关（参考 dsh-im-gateway）：wechat/qq/飞书/邮件/5G 消息/http 统一接入，每会话持久 Agent、回复统一路由。

### B. 多通道模型层（迭代 3，省 token + 高可用）
策略判断/回复/视觉三处可分别选通道，三层优先级 + 自动降级/故障转移：
1. L1 桥接本机已登录桌面 Agent 额度：dsh-workbuddy-connect（GLM-5.3/5.2、DeepSeek-V4-Pro/Flash、Kimi-K3、MiniMax-M3、Hy3/4 等，复用登录态与积分、跟随账号、支持图片与推理等级）、dsh-llm-codebuddy（浏览器 OAuth、无需 Key）；前提桌面 App 常驻。
2. L2 免费模型路由 dsh-free-router：NVIDIA NIM + OpenRouter 免费模型，只选支持工具调用、上下文达标者；按 可用性→等级→首 token 延迟→成功率 排序；限流/超时/服务器/认证失败同轮自动切换，默认每轮最多 4 个；账号级配额不可绕过。
3. L3 自有付费 Key 兜底 + 本地 Ollama 离线通道。
4. 默认 L1/L2 优先、失败逐级降到 L3；第三方永不作唯一依赖。
5. 计费透明：区分“搜索/工具扣 DSH 余额”与“对话扣桌面 Agent 积分”，避免两边扣；显示倍率与免费/折扣徽章、额度用量。
6. 真实溯源：复用官方适配器、不注册虚拟 provider，历史/用量/错误保留真实 provider/model；缓存仅限模型目录与健康摘要。

### C. 深度鉴别引擎（五层全维度侧写）
收到记录严格提取、一项不漏；结论带置信度并随新对话贝叶斯更新，不把对方自述或单条关键词当定论。
- 第一层 · 表层语言指纹（匹配 95%+）：平均句长、口头禅、标点、表情包偏好、平均回复间隔；打字节奏（连甩短消息 vs 攒长文、长串“哈哈”、不爽回单字）；打字细节（固定错别字、语气词、标点偏好）；刻意维持的面具人设、刻意回避话题；“当前不会主动说出口的话”清单（如从不主动道歉、从不说想你、不暴露脆弱）。
- 第二层 · 话题权重系统：按回复长度/积极性做高/中/低权重话题表，模拟时按权重定回复长度与主动度。
- 第三层 · 全维度人格底色（高压场景 85%+）：①大五 OCEAN；②黑暗三联征（自恋/马基雅维利/精神病态）与虐待倾向；③依恋坐标（焦虑/回避；靠近、冷淡时反应）；④情绪模式（稳定性、触发点、爆发或压抑冷战、自愈时长）；⑤权力位势（谁更怕失去、话语权、是否冷暴力/发脾气要挟）；⑥动机意图（情绪价值/陪伴/短期新鲜/长期结婚/走过场）；⑦承诺信用（兑现率高/中/低）；⑧防御风格（被指责：就事论事/合理化/投射甩锅/筑墙，及固定洗白话术，理亏触发）；⑨关系交换倾向（算账交换型/共享型）；⑩共情特征（看懂但冷漠/看懂会安慰/读不懂）；⑪危险信号（Gottman 蔑视、长期冷战、贬低、失控，标 1-5 级风险）。
- 第四层 · 固定对话规则：常规（被夸/被吐槽/邀约/感兴趣话题/冷场）+ 冲突（吵架爆发/吵架之后/被提分手）+ 关系阶段校准（暧昧/热恋/倦怠调整主动度、耐心、长度）。
- 第五层 · 概率波动：所有反应按历史概率随机（如被夸 70 谦虚/20 吹牛/10 调侃；吵架 60 冷战/30 翻旧账/10 服软），禁止同场景每次雷同。
- 伪装与变化：结合长期语境、言行一致性，区分“不经意露馅”与“长期伪装后的疏忽”；“不会说的话”是基于历史的当前边界，真实对话一旦突破即更新、不视为永恒；病理人格（NPD/BPD 等）仅作倾向识别与风险提示，不替代临床诊断。

### D. 用户自我画像（与对方画像配对）
1. 采集用户：性格/大五倾向、沟通风格、实际能力（表达、情绪管理、可投入时间精力金钱）、资源与底线、目标与可接受路径。
2. 来源：简短自评问答 + 用户历史发言（对接风格学习/反哺训练）。
3. 用途：策略与任务基于“用户 × 对方”双方匹配，确保建议在用户能力内、可分步，不输出用户做不到的方案。

### E. 数字分身（高保真模拟 + 对抗预测 + 红队 + 复盘回流）
1. 后台运行，不做“和分身闲聊”娱乐入口；用于预测下一步、实测话术、红队证伪。
2. 高保真硬规则：完全匹配表层指纹，禁止“我理解你”“我们好好沟通”等 AI 套话；按人格底色、反应规则与概率回应该冷淡就冷淡（真实模拟才能准确预测，不为讨好用户 OOC；攻略导向体现在据此选有效话术）；按历史间隔模拟延迟；触雷按回避模式（变短/打太极/转移）；严守“当前不会说的话”；按话题权重回复。
3. 两次自检：①是不是他本人真会说、与历史是否矛盾（矛盾重写）；②有无 AI 味、是否太完美正确（是则改成其糙、直风格）。
4. 数字分身按最新人物信息（侧写/记忆/近期对话/任务/策略）实时联动更新，兼红队主动证伪。
5. 复盘回流：话术/任务执行后录入“对方实际反应”，系统对比“预测 vs 实际”算命中度；差异用于校准五层侧写、分身模拟与人格置信度（贝叶斯更新），连续偏差触发画像/策略修订；复盘沉淀为情景记忆。

### F. 策略/知识引擎（多学科灵活组合、因时制宜）
1. 知识挂载：心理学（依恋/EFT/Gottman/社会交换/认知失调/自我决定等）、法学、经济学、社会学等按需调用，不只挂渣男渣女语录。
2. 心理学效应/定律可组合并标注触发条件与原理：互惠、稀缺、损失厌恶、锚定、贝勃定律、登门槛/留面子、间歇性强化、曝光效应、富兰克林效应、沉没成本、吊桥（唤起归因）、推拉、框架效应等；按场景组合而非单点。
3. 对症判断阀：结合人格/依恋/情绪/阶段/权力位势/话题权重选策略（有人吃冷战、有人越冷越远，不硬套）；人改变后策略更新，不拿老套路对待已改变的人。
4. 关系动态位置法则：判断当前相对权力位置（向上/同层/向下，且随境遇升降）——向上展示重视而非松弛、同层自然不刻意展示努力、向下不展示优越。
5. 输出含：主策略 + 权重、军师建议（下一步 + 停止条件：对方明确拒绝/要求停止时停止推进）、风险提示与行为预测。
6. 攻略校正：所有策略（含边界感、给空间）最终指向引导回归、提升好感与阶段；清除“分手/撤离/放弃/不值得”导向。
7. 特殊情形：对“无事献殷勤/捞取”，目标是识别后反制并引导对等投入、双向奔赴，而非仅识别；策略分“刚猛直给”与“温水煮青蛙/迂回渐进”，按对象与情境切换，不单方面粗暴加码把人逼走。

### G. 任务引擎（教程化引导 + 阶段奖励）
1. 定位：任务本质是“引导教程”，分步让用户照做，而非摆设；每个任务标注提升哪个维度、对终局贡献（无贡献不输出）。
2. 实时生成与跟进：结合当前阶段实时生成；进度按对话自动判断（关键词/语境），不需手动点。
3. 阶段奖励：用户运用技巧达成阶段、对方被引导成功后的正反馈（更主动、兑现、增投入）即“任务奖励”。
4. 软暂停：对方回避激活/愤怒时，“邀约/表白/推进”自动软暂停，转“轻量接触/给空间”。
5. 爽约/失信分支：区分“有事/时间耽误”（延迟 + 改约延伸）与“不想兑现/不放心上/欺骗”（换方式、循序渐进重建或触发策略）；用户已做到而对方不兑现时记录调整。
6. 因人而异：结合用户自我画像安排，可一步到位或分步，控制难度。
7. 联动：任务受鉴别/模拟/六维/财务（单向失衡自动生成“引导对等投入”）/情绪/阶段驱动，结果回写。

### H. 单轮分析输出（悬浮面板）
含：对方真实/可能意图 + 判断把握（模型估计）；主策略 + 策略权重；军师建议（下一步 + 停止条件）；3 条候选 + 归一化推荐权重、每条“为什么这样回”；复制/填入（仅草稿、发送手动）/换一组；“更像我一点”（对接风格学习/反哺训练）；“先照顾好自己的感受”（设等待点、别把单句当定论）；风险提示与下一步行为预测；原文核对页；详细分析三分（已知事实/合理推测/仍未知）。

### I. 话术/方案评分与综合排序（消除多套评分歧义）
三套分数分工：
1. 即时推荐权重（见 H）：模型对 3 条候选的快速归一化排序，作参考。
2. 六维战略分（0-60）：互惠、可靠、吸引、价值观、现实可行、机会成本可控度（各 0-10；“机会成本”记为可控度，分越高=放弃代价越小）；衡量战略质量，不依赖模拟。
3. 模拟实测分（0-100）：以候选为输入让分身模拟对方反应——反应积极度 40（回复越长越延伸越高，“哦/嗯/好”0）、情绪接纳度 30（对方接纳或朝修复缓和方向走越高，抵触/冷淡 0；冲突看是否愿修复而非必须开心）、行动承诺度 20（具体时间/地点/安排越高，推脱打太极 0）、雷点扣分（直接触发本能防御/转移/负面扣 ≥20；战略性给空间不在此列）。
综合排序：
- 模拟可信（准确率约 70%+）：综合分 = 0.6×模拟实测分 + 0.4×(六维/60×100)。
- 样本不足（约 55%）：综合分 = 0.4×模拟实测分 + 0.6×(六维/60×100)，以战略分为准并标注不确定。
- 每条标注：模拟反应、各项明细、六维、综合分、预测有效度（相对推荐，非成功概率）。

### J. 角色档案页 CHARACTER FILE（暗色高级 UI）
关系阶段标签 + 平台/在线状态；好感度双轨（系统心形 0-100 + 用户星级 0-10）；近 10 次互动情绪趋势折线；当前策略卡（名 + 起始日 + 依据）；情绪基线时间线（日期、升温/平稳/降温、分析、情绪分）；近期互动；财务/代价结论与危险信号归档；用户自我画像并列展示。

### K. 方向罗盘（结局对齐，防“步步对、结局错”）
1. 成功的可证伪结构性指标：双向奔赴、承诺兑现率、Sternberg 亲密/激情/承诺、修复力、对等投入（含财务/代价）、稳定性、关系满意度（参考 RAS 与 Rusbult 投资模型：满意度/替代质量/投入规模 → 承诺）。
2. 结局倒推：从成功指标倒推任务与策略，无“对终局贡献”标注的动作不输出。
3. 三重闸门：方向闸（是否朝好结局）、匹配闸（是否对症此人此时）、真伪闸（是否被伪装/表演误导）。
4. 红队与漂移：分身主动证伪；检测漂移即提示并可版本回退；随需求日志全局巡检。

### L. 记忆 / 关系
关系描述字段按实际改写（默认“对方是我的伴侣”易带偏）；聊天历史仅存本机、关联上下文、可配注入条数（0-100），不自动导入全部历史；记忆分析自动进行、无独立入口，备忘录有入口；知识库与联系人、关系走势 K 线、可清空。

### M. 财务分析 + 代价公式（后台）
读取双方财务与付出，整理经济实力与付出档案；代价公式以“付出占其所能承受代价的比例”衡量（拥有 100 万者的 1 元与仅有 1 元者的 1 元主观价值不同）；单向付出失衡触发“引导对等投入”；结合“对方主观是否觉得收支平衡/有无损失”判断损失厌恶能否触发（自觉无损失则难触发）。无前台按钮。

### N. 生理周期日历 + 备忘录（合并入口）
生理周期做成日历，备忘录同入口；纳入女性/男性情绪周期（月经周期、激素节律）作为情绪与策略背景。

### O. NPC 关系网络图
本人与目标周围关键人物（家人/朋友/情敌等）的网状关系图，参考光遇好友列表星图样式；关系网络作为策略考量。

### P. 本地 AI 反哺训练
1. 自用版默认关闭；让本地 AI 越来越像用户（未来他人各自训练）。
2. 数据流：本地采集用户消息、AI 回复及采用/修改/拒绝/纠正四类反馈 → 去重清洗（可导出 Alpaca/ShareGPT）→ 本地低优先级 LoRA（阈值/定时/手动）→ 版本管理（存档/对比/回滚/热加载，基础模型只读）→ 风格相似度四维校验（用词/句式/语气/长度，过低提示回滚）。
3. 数据先本地过一遍，不强制上云。

### Q. 插件系统
一切能力尽量插件化（模型/工具/技能/会话/沙箱/存储/循环/调度/UI），参考 DSH“一切皆插件”与 provider 抽象，便于后续添加。

### R. UI/UX 与数字诚实规范
1. 风格：暗色、高端、大气；可加克制动态背景；无关元素少；后台能力不外露。
2. 窗口：悬浮球在主窗口打开时自动隐藏；多档窗口大小；做好第三档“类豆包快捷浮框”。
3. 数字语义诚实：判断把握=模型主观估计；策略权重=相对选择；推荐权重=候选排序；六维=战略质量；模拟实测分=预测反应；准确率=基于样本量的经验置信区间（非精确概率）；预测有效度=相对推荐。均不等于“回复成功率”；好感度结合阶段与趋势，明确各阶段成功标准，不声称到某数值即成功，永不声称 100% 还原。
4. 准确率标注：<200 条或<2 周【约 55%】；覆盖 1 月+且含 ≥3 次分歧【约 70%】；多轮真人反馈迭代【约 80%】；持续用“预测 vs 实际”复盘回灌校准。

### S. 眼镜终端视觉层（第一视角实时助手，迭代 4 之后落地）
定位：眼镜只做采集 + 显示，重视觉理解放随身手机（近端）或云端；软件内核采用“自定义规则视觉智能体 + 事件驱动推送”，不做全程无差别分析。
1. 采集与预处理：眼镜摄像头第一视角画面，端侧做轻量检测与关键帧抽取（场景变化/人脸/情绪变化/文字出现才触发），不整段上传。
2. 分层理解：端侧轻量模型处理简单项（文字 OCR、人脸/物体）；关键帧送手机/云端视觉大模型深度理解，对接 B 多通道模型层（视觉走支持图片/视频、低成本通道：L1 桥接/L2 免费路由/本地 Ollama，付费兜底）。
3. 识别内容：面前人物身份与表情/情绪/目光、肢体与社交线索、场景/物体、菜单/路牌/价格等文字；结合 C 鉴别、F 策略实时给“对方当前状态 + 该说什么”。
4. 事件驱动呈现：仅在关键事件（对方情绪变化、需要回应、识别到重要信息）推送到 HUD 文字或骨传导语音，避免信息过载；非事件不打扰。
5. 事后复盘：约会/互动后生成视觉复盘报告，回写人物画像、分身模拟与方向罗盘（预测 vs 实际）。
6. 成本控制：抽帧 + 事件触发 + 多通道省钱，禁止持续视频流无节制调用大模型（视频 token 消耗极高）。
7. 隐私合规：拍摄有明示（指示灯等）、本地处理优先、最小化上传，遵守公共场所录像与他人隐私要求。
联动：S 采集 → C 鉴别 / E 分身 → F 策略 / G 任务 → 事件推送；复盘回写 K 罗盘与 J 档案。

## 六、交付步骤
1. 备份现有文件并更新需求日志：按本总纲登记 A-S，标注各模块“联动修改”关系（采集 A → 鉴别 C / 用户画像 D → 分身 E → 策略 F → 任务 G → 输出 H → 评分 I → 档案 J → 罗盘 K，及模型 B/财务 M/记忆 L/眼镜 S 如何喂数据与回写）。
2. 迭代 1 落地并跑通：手动多源采集 → 五层鉴别 → 角色档案 → 高保真模拟 → 话术评分 → 复盘回流，形成最小闭环。
3. 压测迭代 1：多档人设（普通、NPD+回避+童年创伤、BPD 等）各跑数万条自动对话，含“已读不回/数天不回/免打扰”，验证真实生成而非套模板；去知乎等找真实多轮案例（吵架/冷淡/暧昧/分手危机/言外之意）实测，发现问题即修。

6. 每轮封包前自检并跑全部测试，清理测试与个人数据，封包更新 LoveAI；输出“已落地 vs 仍待增强”清单与“心理学效应/定律整合表”。
