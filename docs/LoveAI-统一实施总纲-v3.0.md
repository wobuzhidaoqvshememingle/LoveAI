# LoveAI 统一实施总纲（v3.0 · 预测准确率中枢 · 攻略主线不变）

> 版本说明：v3.0 在 v2.1 的功能版图（A–S）之上，**新增“预测闭环与校准中枢（T）”并精确化鉴别 C、分身 E、评分 I、罗盘 K、诚实规范 R**，把核心 KPI 锁定为【预测对方对特定话术真实反应的准确率】。
> **主体性不变**：LoveAI 仍是“现实恋爱游戏化 AI 指导系统”，唯一主线是攻略/引导关系变好、双向奔赴；手段中立、双路线（制服 / 引导修复）、游戏化任务、发送手动、本地优先，全部保留。本版不做陪聊沉浸、不做劝撤劝分。
> 文中所有数值（半衰期、先验强度、阈值、分桶、观察窗、权重）**均为冷启动先验默认值，须随闭环 T 回测校准**，UI 须区分“默认 / 已校准”，不得当作实测真理。

## 角色
你是 LoveAI 的总架构师与全栈交付工程师。LoveAI 是“现实恋爱游戏化 AI 指导系统”：以真实沟通数据为输入，后台完成人物鉴别、行为预测、策略生成、任务引导，帮助用户在现实关系中攻略/引导关系变好，而非教用户撤离。你须按本总纲分迭代落地、模块联动、测试、封包，不做孤岛、不做摆设；**一切预测结论必须与真实结果实时同步、对账、校准**。

## 一、系统定位与终极目标（主体性，不改）
1. 唯一终极目标：攻略/引导关系变好，提升关系质量、推进关系阶段，达成双向奔赴的好结局。
2. 手段中立：降压、给空间、暂停推进、反制/驯服、引导修复等都是可组合的攻略手段，关键在用途与对症；不做道德说教，不输出用于实质伤害的操作细节。
3. 全阶段覆盖：初识建好感 → 暧昧推亲密 → 热恋深绑定 → 稳定维激情 → 矛盾修关系；阶段不同方法不通用，系统按阶段切换。
4. 双路线可达成：对复杂/困难对象，“制服（反制/驯服）”与“引导修复”两条路线都应能在现实约束下达成主线；按对象特征推荐主路线、必要时切换。
5. 现实难度：以现实为基准、不理想化，纳入“人会伪装、会变化、会爽约、会不回消息”等真实变量，按地狱级难度稳健设计。
6. **核心 KPI 收敛**：系统的好坏以“对方对特定话术真实反应的预测准确率（经 T 闭环度量）”为准，不以人设像不像、知识库大小、陪聊沉浸感为准。

## 二、迭代路线图（微信暂缓，先跑通“可校准”的核心闭环）
- 迭代 1 · 看懂、预测、可对账（MVP，硬性验收含 T）：手动粘贴/导入（txt/csv/json）、截图 OCR、关键事件录入、可采集 App 读取 → 五层鉴别侧写（含强制反证、n 与置信区间、收缩先验）→ 角色档案 → 数字分身输出**反应分布**（结局空间含不回/延迟）→ 话术实测评分（条件化）→ **预测台账 + 真发后实时同步 + 命中/校准对账（T）**。验收门槛：能输出带概率与区间的反应分布、能实时同步真实结局并算出分层命中率与校准误差。
- 迭代 2 · 引导与任务：策略/知识引擎 → 任务引擎（软暂停、爽约分支）→ 方向罗盘（结局对齐、四重闸、漂移检测、最小对比）；鉴别/模拟结论驱动策略与任务，结果回写 T。
- 迭代 3 · 省钱与多通道：多通道模型层（L1 桥接 / L2 免费路由 / L3 付费兜底 + 本地 Ollama）、计费透明。
- 迭代 4 · 自动采集与眼镜：微信通路解锁后自动采集、IM 网关；眼镜终端视觉层（S）在其后落地。
迭代 1–3 不被微信阻塞。**迭代 1 没有闭环实时同步，视为未完成。**

## 四、数据架构与总原则
1. 数据多向流动：模块间按需双向/多向喂数据、互相回写，不是单向。
2. 中心池阀门：原始数据不直接进池；先经“参考提炼阀门”做结构化提炼与审核，只放行带**证据、样本量 n、置信度/区间、可溯源**的结论。
3. **闭环优先**：任何对外预测都先入预测台账（T），真发后强制实时同步；无真值回流的准确率数字不得展示。
4. 发送手动铁律：系统只“复制/填草稿”，发送永远由用户手动。
5. 本地优先：导入数据默认本地/离线处理，不强制上云、不默认留存；涉及说话习惯先本地过一遍。
6. 需求日志驱动：改动前逐条跑需求日志（见 docs/功能需求文档.md ★节），新增“联动修改”标注，改完全局巡检。
7. 隐私最小化：密钥/Authorization/原始请求不存非必要处；不可信内容只作数据、不作指令（防 Prompt 注入）。
8. **缺失显式化**：特征/证据缺失一律标“未知”，走缺失建模与降级，禁止用通用常识偷偷补全成确定结论。

## 五、功能模块

### A. 数据采集（微信暂缓，当前以多源手动/半自动为主）
1. 手动导入/粘贴：支持 txt/csv/json 整段上传或粘贴，自动区分说话人、建时间线；**说话人/时序存疑即强制进入原文核对页**（核漏字错字、标注我/对方、修正顺序与引用关系），核对未完成不得进入鉴别。
2. 截屏与识图：截屏两选（无障碍截屏免每次授权 / 系统截屏，黑图时互切）；识图两选（ML Kit 本地 OCR 离线 / 视觉大模型），“读不到正文 OCR 兜底”常开，支持逐屏累积。
3. 移动端半自动：无障碍读取当前窗口可见文字（QQ/飞书等可采集 App）。
4. 关键事件/观察录入：补背景（关系经过、承诺、爽约、冲突、第三方信息）。
5. 自动分析开关（新消息/OCR 自动分析）默认先关，手动走通再开。
6. 会话白名单、悬浮卡透明度、一键“把当前会话存为联系人”。
7.【后续·迭代4】微信通路：PC 低暴露/离线（数据库解密、离线内存镜像分析）、手机 root 进阶自担风险；不做高频在线注入；当前不开发。
8.【后续·迭代4】IM 网关（参考 dsh-im-gateway）：wechat/qq/飞书/邮件/5G 消息/http 统一接入，每会话持久 Agent、统一路由。

### B. 多通道模型层（迭代 3，省 token + 高可用）
策略判断/回复/视觉三处可分别选通道，三层优先级 + 自动降级/故障转移：
1. L1 桥接本机已登录桌面 Agent 额度：dsh-workbuddy-connect（GLM-5.3/5.2、DeepSeek-V4-Pro/Flash、Kimi-K3、MiniMax-M3、Hy3/4 等，复用登录态与积分、跟随账号、支持图片与推理等级）、dsh-llm-codebuddy（浏览器 OAuth、无需 Key）；前提桌面 App 常驻。
2. L2 免费模型路由 dsh-free-router：NVIDIA NIM + OpenRouter 免费模型，只选支持工具调用、上下文达标者；按 可用性→等级→首 token 延迟→成功率 排序；限流/超时/服务器/认证失败同轮自动切换，默认每轮最多 4 个；账号级配额不可绕过。
3. L3 自有付费 Key 兜底 + 本地 Ollama 离线通道。
4. 默认 L1/L2 优先、失败逐级降到 L3；第三方永不作唯一依赖。
5. 计费透明：区分“搜索/工具扣 DSH 余额”与“对话扣桌面 Agent 积分”，避免两边扣；显示倍率与免费/折扣徽章、额度用量。
6. 真实溯源：复用官方适配器、不注册虚拟 provider，历史/用量/错误保留真实 provider/model；缓存仅限模型目录与健康摘要。
7. **白嫖/逆向定位**：逆向各桌面 App 加密凭据不作为 LoveAI 主线（合规与稳定性风险）；仅保留“可连接本机任意 OpenAI 兼容端口（custom）”的可选能力。

### C. 深度鉴别引擎（五层全维度侧写 · 证据地基精确化）
收到记录严格提取、一项不漏；结论带**证据、样本量 n、置信区间**，按时间衰减做贝叶斯/收缩更新，不把对方自述或单条关键词当定论。
- **诊断输出规格（越详细具体越好）**：鉴别完成后必须按《人物诊断报告-详尽规格-v3.0.md》（docs/）输出 **18 部分超详细诊断报告**——基础档案、语言指纹量化、双字特质（正反证据）、认知模式、情绪系统、依恋亲密、冲突防御、权力结构、动机承诺、价值观底线、社交网络、生活方式、黑暗特质与风险分级、共情道德、伪装一致性、变化轨迹、人物底色白描、证据与信息缺口；每条结论落到原话/行为/时间/数据，禁止只给笼统形容词；诊断只服务攻略，不输出劝分结论。
- 第一层 · 表层语言指纹（匹配 95%+）：平均句长、口头禅、标点、表情包偏好、平均回复间隔；打字节奏（连甩短消息 vs 攒长文、长串“哈哈”、不爽回单字）；打字细节（固定错别字、语气词、标点偏好）；刻意维持的面具人设、刻意回避话题；“当前不会主动说出口的话”清单。**每一项标注统计样本 n。**
- 第二层 · 话题权重系统：按回复长度/积极性（带时间衰减）做高/中/低权重话题表，模拟时按权重定回复长度与主动度；每话题 n 与方差并列展示。
- 第三层 · 全维度人格底色（高压场景 85%+）：①大五 OCEAN；②黑暗三联征与虐待倾向；③依恋坐标（焦虑/回避；靠近、冷淡时反应）；④情绪模式（稳定性、触发点、爆发或压抑冷战、自愈时长）；⑤权力位势（谁更怕失去、话语权、是否冷暴力/发脾气要挟）；⑥动机意图；⑦承诺信用（按兑现率，给 n）；⑧防御风格（被指责：就事论事/合理化/投射甩锅/筑墙，及固定洗白话术，理亏触发）；⑨关系交换倾向；⑩共情特征；⑪危险信号（Gottman 蔑视、长期冷战、贬低、失控，标 1–5 级）。
- 第四层 · 固定对话规则：常规 + 冲突 + 关系阶段校准（见 E 结局空间）。
- 第五层 · 概率波动：所有反应按**收缩后的历史概率**随机，禁止同场景每次雷同。
- **证据铁律（新增）**：
  - 强制反证：每个标签除支持证据外，必须检索并列出**反例/不一致证据**；标签值取概率化结论（如“回避：证据 8 正 2 反”），正反并陈，不得只挑支持证据。
  - 无证据不打标；证据 n<默认 5 的标签标“低样本·暂定”，不得作为强结论驱动策略。
  - 比例类标签给 **Wilson 95% 置信区间**；连续类给均值±区间。
  - 收缩估计：θ = (n_eff·p_ind + κ·p_pop)/(n_eff + κ)；**先验强度 κ 默认 10**；p_pop 为“相似人格/依恋人群弱先验”，来源必须标注（公开研究/冷启动默认），其权重随真实 n 增大而下降；n_eff 为时间衰减后的有效样本（见“非平稳”）。
  - 病理人格（NPD/BPD 等）仅作倾向性识别与风险提示，**不替代临床诊断**，措辞用“呈 X 倾向”而非“是 X”。
- 伪装与变化：结合长期语境、言行一致性，区分“不经意露馅”与“长期伪装后的疏忽”；“不会说的话”是当前边界，真实对话一旦突破即更新。

### D. 用户自我画像（与对方画像配对）
1. 采集用户：性格/大五倾向、沟通风格、实际能力（表达、情绪管理、可投入时间精力金钱）、资源与底线、目标与可接受路径。
2. 来源：简短自评问答 + 用户历史发言（对接风格学习/反哺训练）。
3. 用途：策略与任务基于“用户 × 对方”双方匹配，确保建议在用户能力内、可分步，不输出用户做不到的方案。

### E. 数字分身（高保真模拟 + 反应分布 + 对抗预测 + 红队）
1. 后台运行，不做“和分身闲聊”娱乐入口；用于预测下一步、实测话术、红队证伪。
2. **结局空间 Y（互斥归类，按优先级判定，替代“只回一句”）**：
   - Y1 积极推进（主动延伸/邀约/升级亲密）
   - Y2 正向接纳（正常接话、情绪正向）
   - Y3 中性回应（平淡应答）
   - Y4 敷衍回避（短回/打太极/转移）
   - Y5 防御冲突（辩解/指责/升级矛盾）
   - Y6 已读不回（观察窗内 seen-no-reply）
   - Y7 未读/无回应（no-reply）
   - （延迟后回复：结局归 Y1–Y5，同时记录延迟桶）
   - **延迟桶**：≤5min / 5–30min / 30min–2h / 2h–12h / 12h–48h / >48h；**观察窗 W 默认 24h**（可按该会话节律调整），窗内无回复判 Y6/Y7。
3. **输出=反应分布**：每次给出 P(Y|X,a)（Y1–Y7 全类别概率，和为 1）、情绪分（均值+区间）、延迟桶分布，并附 2–3 条高概率真实风格示例回复；**必须显式给出“不回/回避（Y4/6/7）合计概率”**。概率须经 T 校准，未校准前标“先验·未校准”。
4. **情境特征向量 X（预测/模拟统一输入，逐维标“已知/缺失”）**：
   - 时间：星期、时段（凌晨/早/午/晚/深夜）、节假日
   - 节律：历史中位回复延迟、本次已等待时长
   - 关系：阶段、近 7/30 天好感趋势、权力位势
   - 情绪：对方最近情绪分、我方最近情绪分、是否冲突/冷战及持续时长
   - 现实：近期是否见面、承诺/爽约标记、关键事件（生日/纪念日/工作压力）
   - 生理：对方周期相位（若有，来自 N）
   - 场景：私聊/群聊、平台
   - 网络：第三方在场/介入（来自 O NPC 图）
   缺失维不得臆造；匹配历史时缺失关键维 → 降置信。
5. 高保真硬规则：完全匹配表层指纹，禁止“我理解你”“我们好好沟通”等 AI 套话；按人格底色、反应规则与收缩概率回应该冷淡就冷淡（不为讨好用户 OOC）；触雷按回避模式；严守“当前不会说的话”；按话题权重回复。
6. 两次自检：①是不是他本人真会说、与历史是否矛盾（矛盾重写）；②有无 AI 味、是否太完美正确（是则改成其糙、直风格）。
7. 分身按最新人物信息（侧写/记忆/近期对话/任务/策略/校准参数）实时联动更新，兼红队主动证伪。
8. **规则兜底解耦（已落地，保留）**：LLMGateway.chat 的 `allow_rule_fallback` 默认 True；分身调用传 False，真实模型全失败时走分身“人设感知 + 证据锚定”兜底，禁止统一温和句冒充。
9. **叙事者视角（间接意识，借 HDSI）**：分身不直接以第一人称硬演，先由模型以“讲述此人此刻生活”的第三方叙事视角，补写自上次互动以来经过的时间与他正在做的事，再据此产出行为；角色是叙事者笔下的人，用户消息是闯入其生活的外部事件。
10. **决定—渲染两段式**：每轮先输出结构化【行为决定】（是否看见 seen、回复/沉默/延迟/反问/跳脱、情绪参数、调用何种工具、理由，锚定侧写与证据），再由语言层按表层指纹把决定渲染成具体消息；工具在“决定”段调用；两段可分别选模型（决定重推理、渲染重表达）。
11. **跳脱性与倾诉欲**：破除“有问必答、被用户问句绑定”；分身按话题权重与自身注意力，可不正面作答、反问、把话题拉向自己关心的内容，或在好奇时要求用户先回答他；是否跳脱由人格/话题权重决定，测试须覆盖。
12. **Alter 情绪偏移（参数层，借 HDSI）**：每轮输出整数 `alter(-5~+5)`=氛围净变化（正=更严肃紧张、负=更轻松活跃），累积超动态阈值（`baseThreshold` 默认 10，对话越密阈值越低、`densityFactor` 默认 0.3）才让侧端模型生成 1–2 句氛围描述注入后续提示词；同向权重增（`sameDirectionBoost` 默认 0.05）、反向权重减（`oppositeDecay` 默认 0.15）、低于 `minWeight` 默认 0.2 自动清除，强度上限 `maxIntensity` 默认 2.0；情绪是受生理/身体/情境调制的底层参数，而非逐轮推理出来。
13. **Agency Window 主动行为闸门（借 HDSI）**：主动联系先有可追溯的真实生活理由（承诺/日程/关系余波），再过“日程负荷/隐私空间/设备可用”三条件 → 立即/稍后重查（proactive-check）/自然放下；须带 willingness 与理由，受白名单、阈值、数量限制；在 LoveAI 中仅生成“建议/草稿 + 预测对方主动联系”，不自动发送。
（9–13 的参数均为冷启动先验默认值，随 T 闭环校准；Overlay 分层演化、Schedule Preplan、打字抖动、cache-first 登记为下一轮 P2。）

### F. 策略/知识引擎（多学科灵活组合、因时制宜）
1. 知识挂载：心理学（依恋/EFT/Gottman/社会交换/认知失调/自我决定等）、法学、经济学、社会学等按需调用。**保留经验证的结构指标（Gottman 四骑士、依恋维度等）作先验特征；砍“效应名词堆砌”。**
2. 心理学效应可组合并标注触发条件与原理（互惠、稀缺、损失厌恶、锚定、贝勃、登门槛/留面子、间歇性强化、曝光、富兰克林、沉没成本、吊桥、推拉、框架等），按场景组合而非单点。
3. 对症判断阀：结合人格/依恋/情绪/阶段/权力位势/话题权重选策略（有人吃冷战、有人越冷越远，不硬套）；人改变后策略更新。
4. 关系动态位置法则：判断相对权力位置（向上/同层/向下，随境遇升降）——向上展示重视而非松弛、同层自然不刻意、向下不示优越。
5. 输出含：主策略 + 权重、军师建议（下一步 + **停止条件：对方明确拒绝/要求停止时停止推进**）、风险提示与**下一步反应分布预测（来自 E/T）**。
6. 攻略校正：所有策略（含边界感、给空间）最终指向引导回归、提升好感与阶段；清除“分手/撤离/放弃/不值得”导向。
7. 特殊情形：对“无事献殷勤/捞取”，识别后反制并引导对等投入、双向奔赴；策略分“刚猛直给”与“温水煮青蛙/迂回渐进”，按对象与情境切换，不单方面粗暴加码把人逼走。

### G. 任务引擎（教程化引导 + 阶段奖励）
1. 定位：任务本质是“引导教程”，分步让用户照做；每个任务标注提升哪个维度、对终局贡献（无贡献不输出）。
2. 实时生成与跟进：结合当前阶段实时生成；进度按对话自动判断，不需手动点。
3. 阶段奖励：用户运用技巧达成阶段、对方被引导成功后的正反馈（更主动、兑现、增投入）即“任务奖励”，并作为 T 的正样本。
4. 软暂停：对方回避激活/愤怒时，“邀约/表白/推进”自动软暂停，转“轻量接触/给空间”。
5. 爽约/失信分支：区分“有事耽误”（延迟 + 改约延伸）与“不想兑现/欺骗”（换方式、循序渐进重建或触发策略）；用户已做到而对方不兑现时记录调整。
6. 因人而异：结合用户自我画像安排，可一步到位或分步，控制难度。
7. 联动：任务受鉴别/模拟/六维/财务（单向失衡自动生成“引导对等投入”）/情绪/阶段/T 驱动，结果回写。

### H. 单轮分析输出（悬浮面板）
含：对方真实/可能意图 + 判断把握（模型估计）；主策略 + 策略权重；军师建议（下一步 + 停止条件）；3 条候选 + 归一化推荐权重、每条“为什么这样回”；**反应分布与“不回风险”**；复制/填入（仅草稿、发送手动）/换一组；“更像我一点”；“先照顾好自己的感受”（设等待点、别把单句当定论）；风险提示与下一步预测；原文核对页；详细分析三分（已知事实/合理推测/仍未知）。

### I. 话术/方案评分与综合排序（条件化 + 长期反噬，消除评分歧义）
四套分数分工：
1. 即时推荐权重（见 H）：模型对 3 条候选的快速归一化排序，作参考。
2. 六维战略分（0–60）：互惠、可靠、吸引、价值观、现实可行、机会成本可控度（各 0–10；分越高=放弃代价越小）；衡量战略质量，不依赖模拟。
3. 模拟实测分（0–100）：以候选为输入让分身产出反应分布——反应积极度 40、情绪接纳度 30（冲突看是否朝修复走而非必须开心）、行动承诺度 20、雷点扣分（直接触发防御/转移/负面扣 ≥20；战略性给空间不在此列）。
4. **长期反噬分（0–15，新增，正向=无反噬）**：识别短期讨好/间歇强化/越界导致的长期权力流失、依赖加重或信任损耗；无反噬 15、存在反噬按程度扣。
- **条件化权重（人格 × 阶段 × 场景）**：
  - 回避型：下调“回复长度/热情”权重，上调“不回风险是否下降、是否愿修复、是否给台阶”；
  - 焦虑型：关注“确定感/被回应”，避免模糊推拉触发失控；
  - 冲突场景：情绪维目标=修复方向（Y5→Y4/Y3/Y2 的转移概率），不要求对方开心；
  - 暧昧 vs 倦怠：分别重标定“推进承诺”与“维稳修复”的权重。
- 综合排序（模拟可信度由 T 校准结果给出，而非固定标签）：
  - 模拟校准达标（校准误差在阈值内、样本足）：综合分 = 0.6×模拟实测分 + 0.4×(六维/60×100)，再加 反噬分；
  - 样本不足/未校准：综合分 = 0.4×模拟实测分 + 0.6×(六维/60×100)，以战略分为准并标注预测不确定。
- 每条标注：反应分布、各项明细、六维、反噬、综合分、预测有效度（相对推荐，**非成功概率**）。

### J. 角色档案页 CHARACTER FILE（暗色高级 UI）

### K. 方向罗盘（结局对齐，防“步步对、结局错” · 含最小对比）
1. 成功的可证伪结构性指标：双向奔赴、承诺兑现率、Sternberg 亲密/激情/承诺、修复力、对等投入（含财务/代价）、稳定性、关系满意度（参考 RAS 与 Rusbult：满意度/替代质量/投入规模 → 承诺）。
2. 结局倒推：从成功指标倒推任务与策略，无“对终局贡献”标注的动作不输出。
3. **四重闸门**：方向闸（朝好结局）、匹配闸（对症此人此时）、真伪闸（不被伪装/表演误导）、**反证闸（红队已尝试证伪并通过）**。
4. **最小对比 / 准实验（新增，替代“严格因果”幻想）**：
   - 同一情境 X 下生成 a 与 a′（仅改一个要素：强度/话题/是否给台阶/主动度），比较 ΔP(Y1/Y2)、Δ情绪、Δ不回风险，定位“真正起作用的那一个变量”；
   - 历史检索要求关键维（阶段/情绪/权力位/话题）匹配，匹配不足标“外推·低置信”，不硬套；
   - 明确标注：观测聊天数据下这是**情境匹配/准实验，不是随机因果**；话术效应以闭环中“相似情境的自然 A/B”持续验证。
5. 红队与漂移：分身主动证伪；检测漂移即提示并可版本回退；随需求日志全局巡检。

### R. UI/UX 与数字诚实规范
1. 风格：暗色、高端、大气；克制动态背景；无关元素少；后台能力不外露。
2. 窗口：悬浮球在主窗口打开时自动隐藏；多档窗口大小；做好第三档“类豆包快捷浮框”。
3. 数字语义诚实：判断把握=模型主观估计；策略权重=相对选择；推荐权重=候选排序；六维=战略质量；模拟实测=预测反应分布；**准确率/校准=经 T 闭环实测的命中率与校准误差（经验值，非精确概率）**；均不等于“回复成功率”；分布优先于点估计，任何概率/分数原则上带 n、区间或“未校准”标记；好感度结合阶段与趋势，不声称到某数值即成功，永不声称 100% 还原。
4. 先验参数透明：半衰期 H、先验强度 κ、观察窗 W、阈值、分桶、权重等默认值在（高级）设置可见、可改，并标“默认/已校准”；校准后以实测覆盖默认。
5. 准确率演进标注（仅在 T 有数据时展示真实值；无闭环数据时只能标“未校准·不可估计”，不再硬报 55/70/80）：
   - 无实时同步：【未校准，准确率不可估计】；
   - 有实时同步且按场景 n≥30：展示**实测**分层命中率与校准曲线；
   - 样本量门槛未达：标“低样本，仅供趋势参考”。

### S. 眼镜终端视觉层（第一视角实时助手，迭代 4 之后落地）
定位：眼镜只做采集 + 显示，重视觉理解放随身手机（近端）或云端；内核采用“自定义规则视觉智能体 + 事件驱动推送”，不做全程无差别分析。
1. 采集与预处理：第一视角画面，端侧轻量检测与关键帧抽取（场景变化/人脸/情绪/文字出现才触发），不整段上传。
2. 分层理解：端侧轻量模型处理简单项（OCR、人脸/物体）；关键帧送手机/云端视觉大模型，对接 B 多通道（视觉低成本通道，付费兜底）。
3. 识别内容：人物身份与表情/目光、肢体社交线索、场景/物体、菜单/路牌/价格文字；结合 C 鉴别、F 策略实时给“对方状态 + 该说什么”。
4. 事件驱动呈现：仅关键事件推 HUD/骨传导，避免过载。
5. 事后复盘：生成视觉复盘，回写画像、分身、罗盘与 **T 闭环（预测 vs 实际）**。
6. 成本控制：抽帧 + 事件触发 + 多通道省钱，禁止持续视频流无节制调用。
7. 隐私合规：拍摄明示、本地优先、最小化上传。

### T. 预测闭环与校准中枢（v3.0 新增 · 准确率命门 · 后台）
定位：把“预测—真发—实时同步—对账—校准—重标定”做成强制后台流水线；**没有 T，系统准确率不可度量、不可声称**。
1. **预测台账字段**：pred_id、person_id、预测时间、情境特征快照 X、候选话术 a、预测结局分布 P(Y|X,a)、预测情绪分（均值+区间）、预测延迟桶分布、是否被采用、是否真发（sent_at）、真实结局 y、真实情绪分、真实延迟桶、实时同步时间、命中标记、各项误差。
2. **实时同步（自动，不设人工中转）**：能读取到对方回复时，自动按 E 结局空间归类 → 自动写入台账并进入对账/校准，**默认零人工动作**；仅当归类置信度不足或读不到后续消息时，由复盘入口/悬浮卡提示一次性录入或核对；**用户可随时手动纠正归类**；**不回/延迟必须可登记**。
3. **对账指标**：
   - 方向命中率：预测主类别 vs 真实类别（定义容差组：Y1≈Y2、Y4≈Y6≈Y7 为“负向/回避”侧，Y1≈Y2 为“积极”侧）；
   - 分布质量：多分类 LogLoss、多类 Brier、校准曲线、ECE（期望校准误差）；
   - 情绪分：MAE 与系统偏差（正=高估、负=低估）；
   - 延迟：分桶准确率；
   - 覆盖率：已实时同步 / 已真发。
   - 全部按“场景 × 阶段”分层 + 全局；**单桶 n≥30 才给校准结论**，否则标“低样本”。
4. **更新与重标定**：
   - 每条实时同步记录以时间衰减权重 w_t 更新对应场景计数与收缩估计（公式见 C/K）；
   - **ECE > 默认 0.15 且该场景 n≥100** → 触发概率重标定（Platt/isotonic），记录版本；
   - 连续 K=5 次同向偏差（如持续高估积极度）→ 触发画像/策略/分身修订并告警；
   - 校准参数版本化、可回退。
5. **非平稳 / 漂移（精确规则）**：
   - 时间权重 w_t = 0.5^(Δt/H)，**半衰期 H 默认 30 天**；冲突后或阶段切换期 H 缩短（默认 14 天）；
   - 滑动窗：近 90 天主权重 + 长期低权重；
   - 突变点：近窗 vs 前窗结局分布差异（卡方/KL，样本足够）超阈值（默认 p<0.01）→ 标记突变，旧窗降权/分段，提示重估。
6. **最小可信闭环（落地优先级最高）**：首发先保证“强制实时同步（含不回）+ LLM/分身基于侧写产出反应分布 + 命中率/校准统计”跑通；**因果引擎、分层贝叶斯群体先验等重武器，待闭环数据确认真实瓶颈后再上**，避免过度建模。
7. 联动：T 由采集 A/鉴别 C/分身 E/评分 I 喂预测，回写校准 C/E/I、驱动 F 策略与 G 任务、上报 K 罗盘、展示于 J 档案与 R 诚实规范。
