# LoveAI 统一实施总纲 · v3.1 加固补丁（配套 v3.0 使用）

## 〇、本版性质与主体性确认
- 本文件是 v3.0 的**增量补丁**，不替代、不推翻 v3.0；v3.0 全部条款继续有效，v3.0 + 本补丁即最新完整版。
- **主体性原样保留**（v3.0 第一节，不改）：攻略/引导关系变好、双向奔赴为唯一主线；手段中立；双路线（制服 / 引导修复）；游戏化任务与档案；全阶段覆盖；发送手动；本地优先。本版不做陪聊沉浸、不做劝撤劝分。
- 经逐项核对，第三方红队评审的**主干级建议已在 v3.0 落地**：预测闭环 T、情境特征向量 X、强制反证、收缩估计、结局空间与反应分布、校准与重标定、漂移突变检测、数字诚实规范。
- 本补丁只补"机制化 / 边界条件"层面的残余漏洞，不做重构；补丁中所有数值仍为冷启动先验默认值，随 T 闭环校准，UI 区分"默认 / 已校准"。

## 二、加固补丁条目（可直接并入总纲对应模块）

### P-01 证据量 → 置信上限硬封顶（补 R/T）
- 同场景**有效证据 n_eff**（时间衰减后）映射置信上限：
  - n_eff < 5：仅"假设"，不驱动策略、不展示概率档；
  - 5–9：上限 ≤45%；10–29：≤60%；30–99：≤80%；
  - ≥100 且校准达标：不封顶，以 T 实测命中率为准。
- 命中 P-04 降档情形时，在原档基础上**再降一档**。
- 作用：把"小样本伪精度"用硬门控拦下，不依赖模型自觉。

### P-02 校准科学口径（补 T）
- 对账同时给：可靠性图、ECE、多类 Brier，并做 **Murphy 分解（可靠性 / 分辨度 / 不确定性）**；只校准而无分辨度（不能区分高/低风险场景）的输出判为无效。
- 校准在"用户已决定并实际发送"的条件下进行；**未发送候选的反应不可验证，其模拟分永不进入准确率报告**，仅作合理性参考（UI 须明示）。
- ECE 双线：0.15 为告警/重标定触发线（v3.0 已有），**0.10 为稳态达标线**。

### P-03 预测即干预 · 静默金标准（补 T/E，关键）
- 风险：系统预测会改变用户发送行为，回流的是"被建议过滤后"的分布，校准被系统性污染。
- 机制：随机抽取默认 ≥20% 的对话轮次进入**静默子样本**——该轮不向用户展示预测/建议，仅后台存档预测，事后用真实结果校准，作为金标准；其余轮次校准结果须与静默子样本对照，出现系统性差异即证明建议改变了行为分布，并据此修正。
- **回填默认轻量化**：发送后自动预填真实结局、用户一键确认，降低回填门槛、防"只在顺利时反馈"的幸存者偏差。

### P-04 样本外/高压强制降档 与 先验切换（补 E/R/T）
- 降档白名单：冲突升级、高情绪唤醒、冷战后重启、场景新颖度（与历史库最近邻距离）超阈值、T 检出行为分布突变。
- 动作：置信强制降档 + 标准披露措辞——"历史上类似情况下约 Y% 出现 Z；当前情境样本少，仅供参考"；禁用"一定/肯定/他不会"等确定性语言。
- **剧变期切换**：新关系初期、激烈冲突后、重大变故期，主干临时由"个体历史分布"切回"人群先验 + 强降档"，历史库降为参考。
- **非典型个体**：以最初约 50 条消息检验该个体与人群先验的偏离；偏离过大则放宽收缩 κ 并整体降档，避免把非典型个体错误拉向人群均值。

### P-05 标签防漂移 与 防自我确认（补 C/T）
- 标签 schema 与生成模型**双版本化**；任一变更须重放重标存量标签并出 diff 报告。
- **标签生成通道与预测/分身模型物理分离**（不同模型或不同 prompt 体系），双通道一致率以 Cohen's κ 衡量；类别 κ<0.7 冻结该类标签，按周人工抽检，低于门槛回滚。
- 每个标签继续绑定原文引用 + n + 区间 + 反证（v3.0 已要求反证，本条补"通道分离"）。

### P-06 伪装识别 与 侧写慢更新（补 C）
- **证据独立性**：同一混杂簇（如"周末 + 深夜 + 同一话题"）内多条线索只计一次；稳定倾向需 ≥3 个不相关情境方向一致；基线一律用个体内 z 分数，不用人群规范。
- **露馅信号**（延迟分布突变 / 回避模式 / 风格一致性下降 / 情绪词与内容错位 / 承诺具体性下降）触发"自然解释清单"排除（外部事件 / 设备 / 工作周期 / 时段变化）；排除不掉且重复 ≥3 次才入"待验证假设池"，单次暴露永不输出；过程控制用 CUSUM 类方法而非单一阈值。
- **强制反向陈述**：任何异常结论同时给出"此判断可能不成立，因为…"。
- **更新步长受限**：单次更新最多移动 k=1 个后验标准差，防反复横跳；重大跨档改判需多模型一致 + 跨场景证据齐备 + 入审计日志；旧证据指数遗忘沿用 T 的 H。
- **高功能/强一致性伪装**：多证据仍可能自信地错，故系统只"报告异常模式"，永不下人格判决；临床类只做倾向提示（重申 v3.0）。

### P-07 拒绝信号自动降级（补 E/F/G，红线）
- 识别**明确拒绝**（"别说了/不想聊"）与**暗示性拒绝**（连续单字、话题反复转移、长冷模式）：触发后分身/任务/话术统一降级为"尊重边界、停止推进"，邀约/表白/推进类任务立即软暂停（沿用 G.4）。
- 与主体性协调：本条只拦"骚扰式推进"；针对"捞取/不对等"的反制与"引导对等投入"主线不受影响，仍以双向奔赴为目标。

### P-08 防操纵红线 与 分层同意（补 R，协调手段中立）
- **拒绝生成**：冒充/欺骗、威胁、制造内疚、jealousy 诱导、煤气灯、骚扰/查岗监控类话术；命中即拒绝，并可转述为真诚、非监控的表达。
- **红线边界（保护主体）**：反制/驯服、推拉、框架、给空间等中性手段不属此列；红线仅划在欺骗、违法、伤害、骚扰、未授权访问。
- **分层知情同意**：导入前明示"模型会出错、预测不保证未来、你在分析一位无法对此同意的人（关系伦理由用户自担）"；隐私最小化与"本地处理"须有工程证据；一键删除覆盖衍生标签/索引（并说明备份保留策略）。
- **防依赖**：产品定位"帮你组织你想说的话"，周期性"系统局限回顾"，不承诺"完美下一句"。

### P-09 第三方数据外溢防护（补 A/C）
- 导入记录可能夹带第三方（群聊他人、对方家人）的个人信息、证件、照片：入库前做 PII 检测与提示，默认不将第三方个人信息纳入可检索标签，提供脱敏/排除选项。

### P-10 无 LLM 纯本地韧性 + 供应商训练政策（补 B/T）
- 降级链末级：所有生成模型不可用时，仍以"收缩后的历史概率 + 情境检索"输出统计型反应分布（标注"无生成模型，仅统计预测"），不硬失败。
- 供应商注册表新增字段：**是否用用户请求训练模型、数据驻留地**；"不训练/本地处理"承诺作为路由与展示条件。

### P-11 评测与压测纪律（补交付步骤）
- **影子三阶段**：纯影子（只存档不展示）→ 展示预测不排序 → 全功能；每阶段以静默子样本命中率显著优于人群基线为准入。
- **合成数据**（多画像/自由生成对话）只用于回归与鲁棒性，其分数不对外作准确率；真实准确率只来自真人数据 + 时间切分。
- **对抗集**：真人对话上做最小语义扰动测稳定性；注入"侧写与当下反应矛盾"样本测改判能力。
- 需求级验收增补三项：①置信档区分度（低置信档实际错误率显著高于高置信档）；②情境检索消融（关闭检索后准确率下降幅度）；③建议采纳后 1 周回访"后悔率"。
