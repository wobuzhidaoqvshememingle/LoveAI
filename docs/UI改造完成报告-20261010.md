- **12 秒呼吸光斑**：main.css `body::before`，position:fixed / pointer-events:none / z-index:0，径向渐变 rgba(201,163,106,0.08→0)，60vmax，@keyframes breathe 12s ease-in-out infinite alternate，scale 1→1.15 + opacity 0.5→1

## 九、P0 追加：沉浸式语音桌面模式骨架（R3.3-49）

### 9.1 需求
全屏暗色无边框窗口 + 右侧半透明立绘 + 中央发光语音球（蓝/橙/紫三态）+ 底部字幕条。whisper STT → 策略引擎 → edge-tts TTS 流程骨架。F11 切换。

### 9.2 新建文件

| 文件 | 说明 |
|---|---|
| `app/widgets/immersive_mode.py` | `ImmersiveMode(QWidget)`：全屏无边框暗色背景 #0a0908，QPainter 画语音球（idle 蓝 #4a9eff / recording·thinking 橙 #ff8a3d / speaking 紫 #c084fc）+ 光晕动画，右侧半透明立绘占位（QPainter 人形轮廓），底部字幕条，顶部关系阶段标签 |

### 9.3 公开方法
- `set_mode(state)`：idle/recording/thinking/speaking
- `show_subtitle(text, duration)`
- `set_stage_label(text)`
- `close_immersive()` / `toggle_fullscreen()`
- 信号 `immersive_closed`
- 快捷键：F11 切全屏，Esc 关闭，点球切录音

### 9.4 window_manager 接线
- VALID_WINDOWS 加 "immersive"
- `_create_window` 加 immersive 分支（创建 ImmersiveMode，连 immersive_closed 信号）
- 沉浸式不参与几何持久化（全屏）
- 进入沉浸式时自动隐藏主窗口和悬浮球；退出时恢复悬浮球
- `open_window("immersive")` 即可打开

### 9.5 Graceful Degrade
| 依赖 | 不可用行为 |
|---|---|
| QAudioRecorder | stub 3 秒后自动进 thinking |
| transcribe_audio_file 失败 | 字幕条显示错误，回 idle |
| 策略引擎失败 | 字幕条显示"策略异常"，仍切 speaking |
| edge-tts 未安装 | 仅字幕显示，按字数估时回 idle |
| facade=None | 策略回复显示"facade 未注入" |

### 9.6 后续可选项
- 立绘换真实 PNG / Live2D 模型
- 接入真实录音设备（QAudioRecorder 当前 stub）
- edge-tts 实际安装并播放
- F11 全局快捷键绑定（当前仅窗口内有效）
