## 四、手段中立核查结论

- 全部效应（89 条）及输出中：**无"禁止使用/绝对不要/严禁/不可使用"道德裁决**（grep 强禁令词在 services/ 活跃 .py 与手册中均为 0）
- 每条手段统一呈现：**原理 → 适用条件 → 使用方法 → 预期效果 → 代价与风险 → 失效条件**
- 危险效应（煤气灯/鲶鱼/维特/斯德哥尔摩）：识别/预防为主，反向使用代价如实陈述
- 系统**默认推荐主线为修复引导**，但手段库平等中立、选择权在用户；用户选非默认手段时提供完整信息+代价提示，不阻拦、不道德评判

## 五、能力边界（如实说明）

**本地规则可稳定覆盖**：
- 关键词/结构模式：冲突、金钱、冷淡、暧昧、邀约、表白、分手、承诺
- 时序/对话结构：提议-否定循环（挑剔/作）、嘴硬破冰、借日常事务递接台阶、深层脆弱自我暴露、补偿动作识别
- 黑暗三角/煤气灯/辱骂信号的关键词画像

**本质依赖 LLM 深度分析（当前为已知边界）**：
- 更隐晦的反语、隐喻、双关（字面与意图完全相反且无结构特征时）
- 长程关系动态（需数月行为基线，如 deception_detector 的≥3月设计）
- 跨文化/极个性化的暗号式表达
- 多轮情绪曲线的细腻归因

这些场景在 LLM 链路补齐前，系统会以"本地规则能确定的部分 + 如实标注数据不足/需更多上下文"方式降级，不会编造结论。
