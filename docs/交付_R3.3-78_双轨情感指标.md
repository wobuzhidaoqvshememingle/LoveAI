## 3. 双轨数据流

```
[分析侧]
analysis_orchestrator
  └─ manipulation_coach 输出（反制/引导判定）
        │
        ▼
app/service_facade._update_affection_from_analysis
  ├─ resolve_route(manipulation 输出)   ──► 判定 counter / guide
  └─ set_route(route)                    ──► 写入内存态当前路线
        │
        ▼
[任务侧]
services/task_engine
  ├─ get_route()            ──► 读取当前路线
  ├─ _anchor_for(route)     ──► 按路线选奖励锚点（counter→loyalty / guide→affection）
  ├─ _create()              ──► 写入 route / loyalty_reward 字段（DB 幂等迁移两列）
  └─ _complete()            ──► 双发放：
        ├─ counter 线 → affection_engine.add_loyalty_bonus(...)
        └─ guide   线 → affection_engine.add_bonus(...)
        │
        ▼
[指标侧]
services/affection_engine
  ├─ scores["loyalty"] 独立存储（与 scores["affection"] 并列，不合并）
  ├─ 独立衰减：LOYALTY_DECAY_RATIO=0.012（好感衰减 0.005）
  └─ loyalty 变化 ──► 发出 loyalty_changed 信号
        │
        ▼
[展示侧]
app/signals.loyalty_changed
  ├─► app/widgets/status_bar.py  →  ❤好感 / 忠忠诚 双标签分开展示
  └─► services/bridges/loyalty_pet_bridge.py (LoyaltyPetBridge, 事件 LOYALTY_CHANGED)
        │
        ▼  WebSocket
desktop-pet-electron
  ├─ renderer/js/emotion.js：接收 loyalty 字段 → detectRise(metric, delta) 三态判定
  └─ renderer/js/app.js：
        ├─ metric=loyalty   → feedbackLoyaltyRise()  顺从姿态/文案
        └─ metric=affection → feedbackAffectionRise() 亲昵姿态/文案
```

路线权重（`services/dual_track.py` ROUTE_WEIGHTS）：
- **counter（反制线）**：loyalty 0.4 / affection 0.15 —— 主指标忠诚
- **guide（引导线）**：affection 0.4 / loyalty 0.1 —— 主指标好感
