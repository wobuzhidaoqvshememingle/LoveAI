## 一、需求背景

现有需求覆盖多由用户逐条点出，缺"主动领域建模"。本轮主控主动排查出 6 大类
长期未覆盖的现实复杂度（家庭系统 / 里程碑事件链 / 法律与状态边界 / 复合纠缠 /
条件差与主导权 / 心理创伤驱动），全部登记并落地为可运行代码，而非"登记即删"。
铁律继承自 R3.3-77：法律类仅合规风险提示、伦理/心理类仅分析标记不评判、
干预文案禁教唆；所有识别必须可观测（真实运行输出贴证）。

## 六、合规说明

- **法律仅风险提示口径**：财产署名/共同负债只产出 `legal_risk_prompts` 合规提示文案，
  不输出任何违法指导、规避手段或教唆内容；落库任务文案明示"仅做合规风险提示"。
- **伦理仅分析标记不评判**：收入差/家庭条件差/创伤/继子女接受度等只做 `detected/level/adaptation`
  结构化标记与策略适配，不对任何人贴道德标签、不做价值褒贬。
- **干预文案禁教唆**：复合循环干预文案全部为"冷静期/自我复盘/边界练习/差异化自我建设"
  等自我建设与边界类任务，不含报复、操纵、PUA、纠缠对方的教唆话术；
  `knowledge\real_complexity_scenarios.md` 话术库同口径。
