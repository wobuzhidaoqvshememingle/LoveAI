# 人物诊断报告 · 详尽输出规格（v3.0 · LoveAI 鉴别引擎 C 配套）

> 用途：本文件是鉴别引擎 C 的**诊断输出模板与提示词**，可直接在 LoveAI 内核或其他 AI 窗口使用。目标只有一个——把对方**诊断到极详细、极具体、可核对**：每条结论落到**具体行为、原话证据、时间点、场景、数据**，而不是停留在“他很冷漠 / 他挺热情”这类空泛形容词。
> 主体性：诊断服务于“攻略/引导关系变好”。本报告**只做事实与倾向诊断，不输出劝分、撤离、放弃结论**；病理内容只作倾向提示，不替代临床诊断。

---

## 〇、诊断总要求（先读，硬性）
1. **具体优先**：能写“他连续 3 次在我提‘我们’后把回复从平均 18 字压到 2–3 字并转移话题（原话：‘先不说这个’，10-05/10-07/10-08）”，就不准写“他回避亲密”。先给行为和原话，再给标签。
2. **证据锚定**：每条判断后挂【原话/行为 + 时间戳 + 出处】；无证据写“待观察”，**严禁臆断、脑补、套用流行心理学刻板印象**。
3. **正反并陈**：每个特质同时列正例与反例，给“几正几反”、概率、样本量 n、置信区间；不得只挑支持证据。
4. **量化到位**：凡可统计的（句长、间隔、主动占比、兑现率、情绪分）一律给数字 + 分布 + n。
5. **颗粒度细**：按下面 18 部分逐项填，**不准漏项**；某部分确实无信息，写“暂无信息”，并在第 18 部分列入“待观察清单”。
6. **病理谨慎**：用“呈 X 倾向 / 在 X 维度得分偏高”，不用“他是 NPD/BPD”；临床类结论一律加“不替代专业诊断”。
7. **白描收尾**：最后必须有一段生活化、非术语的“人物底色白描”，让人读完如见其人。

---

## 一、基础档案
- 平台与渠道：主要在哪些 App 互动、各占比；私聊/群聊。
- 关系阶段与时长：当前阶段（初识/暧昧/热恋/稳定/矛盾倦怠）+ 判断依据；认识时长、互动跨度。
- 可推断属性：性别、大致年龄段、职业/身份、所在城市——**每项标“已知 / 推断（证据）/未知”**。
- 数据概况：总消息数、对方消息数、时间跨度、是否含冲突/见面/承诺事件（决定诊断置信度）。

## 二、语言指纹（量化，越细越好）
1. 句子形态：平均句长、句长分布、短句（≤6字）占比、长段（≥30字）占比；习惯“一次甩 N 条短消息”还是“攒一段长文”，给典型连发条数。
2. 标点习惯：句号/问号/感叹号/省略号/波浪号/不打标点的使用频率与场景；是否爱用叠用标点（？？！！……）。
3. 语气词与口癖：啊/呀/呢/嘛/呗/哈/哦/嗯/喂/啧等词频与使用情境；高频口头禅原话（列 Top 清单 + 出现次数）。
4. 表情系统：表情包类型（萌宠/搞怪/怼人/撒娇/阴阳）与频率、Emoji 偏好、特定表情的固定含义；长串“哈哈”的写法（哈/哈哈/哈哈哈哈）与触发场景。
5. 文字细节：固定错别字、方言、网络用语、缩写、数字/英文混用习惯；正式 vs 随意措辞差异。
6. 回复节律：回复间隔中位数/均值/分布、最快与最慢、延迟六桶占比（≤5min/5–30min/30min–2h/2h–12h/12h–48h/>48h）；活跃时段、昼夜差异；忙时是否告知、聊嗨时与不爽时（是否回单字/已读不回）的语言变化。

## 三、性格特质（双字标签 + 证据 + 反证）
1. 大五 OCEAN 逐维：开放性/尽责性/外倾性/宜人性/神经质，各给倾向（高/中/低）+ 具体行为证据 + 反例。
2. 提取 **8–15 个双字核心特质**（如：嘴硬、务实、敏感、好面、吃软、护短、拧巴、洒脱、算计、念旧……），每个按格式写：
   - 标签 ｜ 正例（原话+时间）｜ 反例（原话+时间）｜ 几正几反 ｜ 置信度（高/中/低）。
3. 明确他在聊天里**刻意维持的面具人设**，以及人设与私下行为的初步反差。

## 四、认知与思维模式
1. 归因风格：遇问题习惯内归因还是外归因；是否“双标”（对己宽、对人严），给对照原话。
2. 认知偏差（CBT 视角逐条核对 + 证据）：非黑即白、以偏概全、读心术、灾难化、情绪推理、应该句式、贴标签、个人化。
3. 关注焦点与决策：聊天注意力落在人/感受/事情/金钱/面子哪一类；决策风格（理性权衡/冲动/犹豫拖延/从众）；时间取向（沉湎过去/活在当下/规划未来）。
4. 思维表达：直给还是绕弯、是否话里有话、反话/讽刺的使用频率与识别线索。

## 五、情绪系统（细到触发点与恢复）
1. 情绪基调与稳定性：常态情绪、稳定性高低、波动幅度与频率；正性/负性情绪占比（给情绪分趋势）。
2. 触发点清单：**具体事件/话题 → 具体情绪反应 → 原话**（至少列 5 条，含正性触发与负性触发）。
3. 情绪表达与处理：外放爆发 / 压抑冷战 / 隐忍后翻旧账；情绪上来时的典型话术与行为；自我恢复时长；是否需要他人哄、还是自己消化。
4. 关联因素：情绪与时段、生理周期、工作压力、见面与否的关联（有则给证据）。

## 六、依恋与亲密模式
1. 依恋坐标：焦虑分/回避分/安全分（数值 + 证据），判定安全/焦虑/疏离回避/恐惧回避倾向。
2. 关键反应：你主动靠近时、你冷淡/延迟回复时、被忽略时、面对分离或“分手”字眼时，各自的具体反应与原话。
3. 亲密表达：如何表达喜欢与想念（语言/行动/身体/物质）、频率；吃醋模式；安全感来源；对“确定关系/未来/承诺”话题的反应。
4. 关系痕迹：若提及成长经历或前任，记录其与当前依恋模式的关联（只作背景，不深挖隐私）。

## 七、冲突与防御模式（重点，逐项证据）
1. 冲突触发点：哪些事一触就炸/就冷，列清单。
2. 第一反应类型：战（指责/提高音量）、逃（消失/冷战）、僵（沉默对抗）、讨好（哄/求和）的占比与触发条件。
3. 冲突战术清单（出现即记原话）：指责、翻旧账、倒打一耙、合理化找借口、投射甩锅、筑墙不回应、拉黑/分手威胁、人身攻击、摔东西。
4. 固定洗白话术：理亏时的原话模板（如“我都是为你好”“是你想多了”“你非要这么想我也没办法”）。
5. 修复模式：冲突后谁先低头、修复方式（冷处理几天/买礼物/道歉/假装翻篇）、平均修复时长；是否记仇、是否反复重提。
6. 底线行为：冲突中有无越界（威胁、动手、毁坏物品、侮辱人格），单列并对接第 13 部分风险分级。

## 八、关系定位与权力结构
1. 主动度：对方主动开启话题次数 vs 我方，主动占比（数字）；邀约由谁发起。
2. 话语权：做决定时最终听谁的次数统计；分歧时谁让步。
3. 投入四账：时间投入、情绪投入、金钱投入、行动投入，各自的具体表现与对等程度。
4. 权力位势：谁更怕失去、当前向上/同层/向下及变化；是否使用冷暴力、发脾气、内疚感、经济作为控制手段。
5. 角色定位：关系中像照顾者/被照顾者/平等伙伴/博弈对手，给证据。

## 九、动机、诉求与承诺信用
1. 核心诉求排序：情绪价值/陪伴/性/物质帮助/结婚成家/短期过渡/面子社交——按证据排序，标置信度。
2. 真实意图：他在这段关系里要什么、短期目标与长期意愿；投入是递增还是递减。
3. 承诺信用表（逐条）：承诺内容 ｜ 承诺时间 ｜ 是否兑现 ｜ 兑现/失信证据；统计兑现率（高/中/低 + n）。

## 十、价值观与底线
1. 观念画像：金钱观（消费/储蓄/为谁花/AA 或大方）、婚恋观、家庭观、事业观、社交观，各给原话或行为证据。
2. 雷点/逆鳞清单：话题或行为 → 他的反应 → 证据；明确“绝对不能碰 / 碰了会怎样”。
3. 道德边界：在哪些事上有明确原则、哪些事上灵活或无底线，给对照。

## 十一、社交与关系网络
1. 社交圈：朋友数量与类型、挚友特征、群体中的角色（主导/跟随/边缘）。
2. 家人关系：与父母/兄弟姐妹的关系亲疏与相处模式（依恋渊源，仅记录其自述）。
3. 异性边界与第三方：与异性相处尺度、前任/情敌动态、是否存在三角关系；关键人物（家人/朋友/情敌）对他的影响力，对接 NPC 图。

## 十二、行为模式与生活方式
作息规律、工作/学习状态与上进心、爱好及投入程度、消费与生活习惯、烟酒游戏娱乐、现实行动力（说到做到 vs 拖延）、生活自理能力；每项给具体表现而非评价。

## 十三、黑暗特质与风险信号（谨慎、重证据）
1. 黑暗三联征：自恋、马基雅维利、精神病态各维度倾向（高/中/低）+ **具体行为证据**，无证据不打标。
2. Gottman 四骑士：批评、蔑视、防御、筑墙的出现频率与原话。
3. 操控手段核对（出现即记录并给原话/时间）：煤气灯（否认现实/扭曲记忆）、轰炸示爱（love-bombing）、间歇性强化、三角测量、贬低打压、孤立社交、内疚操控、经济控制、未来承诺拖延（future-faking）。
4. 风险事件时间线：按时间列出越界/伤害/极端行为；**危险信号分级 1–5**（1=偶发口角，5=人身威胁/暴力/严重精神操控），给分级依据。

## 十四、共情与道德情感
1. 共情拆解：认知共情（懂不懂你怎么想）与情感共情（在不在意、会不会心疼）分别评估 + 证据；是“看懂但冷漠 / 看懂会安慰 / 根本读不懂”。
2. 道德情感：利他与自私表现、愧疚感、感恩、对弱者或动物的态度。
3. 道歉能力：是否真道歉、道歉模式原话（真认错 / 敷衍“行了吧” / 倒打“我道歉但你也有错” / 从不道歉）。

## 十五、伪装与一致性
1. 面具清单：他刻意经营的形象（如大方/洒脱/无害/深情）。
2. 言行对照表：**“他说的” vs “他做的”**逐条并列，标矛盾点；不经意露馅的瞬间（原话/场景）。
3. 情境差异：压力下 vs 放松时、人前 vs 私下、追求期 vs 得到后的差异。

## 十六、变化轨迹（时间线）
分阶段（初识/暧昧/热恋/矛盾/现在）描述行为与态度演变；列关键转折点（事件→变化）；被引导或干预后发生的变化；总体趋势（向好/向差/波动），对接 T 的漂移检测。

## 十七、诊断结论（白描 + 核心标签 + 相处要点）
1. **人物底色白描**：300–600 字生活化白描，具体到说话方式、处事惯性、情绪逻辑、在关系里的真实模样，**不用术语堆砌**，如见其人。
2. 核心标签：3–5 个最能定义他的双字标签，各配一句最硬的证据。
3. 相处要点（攻略导向，对接策略 F）：他吃哪一套（吃软/吃硬/吃尊重/吃稀缺/吃台阶）、忌什么、最容易被什么打动、最易被什么激怒或逼退。
4. 风险与禁忌：必须规避的雷区与需要警惕的信号；**在此基础上给“如何对症引导关系变好”的方向，不给撤离结论**。

## 十八、证据、可信度与信息缺口（附录）
1. 证据索引：本报告引用的原话/行为清单（编号、时间、出处），可逐条回溯。
2. 可信度统计：样本量 n、时间跨度、正反证据计数、关键结论的置信区间；校准状态（对接 T：未校准 / 已校准命中率与 ECE）。
3. **待观察清单**：目前还不知道、需要在后续互动中验证的具体问题（如“他是否会在冷静后主动兑现邀约”），并写明“看到什么信号即可补全/证伪”。

## 输出格式细则
- 每条结论推荐格式：`结论（双字标签/倾向）——具体行为或原话【时间】（正x/反x，n=，置信度）`。
- 双字标签用于凝练；其下必须有具体证据，**禁止只有标签**。
- 表格优先用于：语言指纹量化、承诺信用、言行对照、风险时间线、触发点清单。
- 信息不足时：宁可输出详尽的“待观察清单”，也不降低标准去硬凑结论。
- 全篇只陈述事实与倾向，不做道德审判，不替用户决定去留；诊断的终点是“看懂之后如何对症攻略、引导双向奔赴”。
