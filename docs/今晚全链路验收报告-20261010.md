## 六、修了哪些bug（实际修了3个）

### Bug 1：数据不足时依恋分数全给50，关键词命中被浪费
- **问题**：persona_analyzer 在消息<30条时，不管关键词命中多少，依恋分数全给50默认值。导致"我需要空间""别这么黏人"这种明确回避信号也无法把分数推过阈值，人格倾向永远触发不了策略。
- **修复**：`services/persona_analyzer.py` 第796-800行，数据不足时改为以50为基线，每条关键词命中+5分（上限70）。
- **效果**：2条回避关键词命中后，avoidance_score从50→60，avpd(回避型人格)从0分→2分。
- **备份**：`persona_analyzer.py.bak`

### Bug 2：人格倾向没到阈值时build_strategy返回空
- **问题**：`personality_strategy.build_strategy()` 在没有任何人格倾向达到MIN_SCORE=3.0时直接返回空列表。但此时依恋类型已经判断出来了（回避/焦虑/恐惧），应该给基本策略。
- **修复**：`services/personality_strategy.py` build_strategy 加fallback：人格诊断没触发时，按依恋类型(avoidant/anxious/fearful)返回3条推荐动作+3条禁忌+引导文案。仅在attachment是dict（有真实分数）时触发，不影响字符串形式的测试。
- **效果**：回避型聊天现在能输出"给对方空间/低压力联系/等对方主动再热情"3条策略，不再返回空。
- **备份**：`personality_strategy.py.bak`

### Bug 3（新建）：R3.3-47 行动面板不存在
- **问题**：识别到人格/依恋/操纵/阶段后，结果散落在orchestrator的各个字段里，用户看完分析不知道"该怎么办"。
- **修复**：新建 `services/action_panel.py`，`build_action_panel(orch_result)` 把识别结论+策略推荐+3条任务+3条具体话术+风险提示聚合成一个面板。话术按场景/人格类型自动选模板（avoidant/anxious/fearful/npd/bpd/flirting/money_danger/default）。
- **效果**：输入orchestrator结果，输出一个干净的dict：summary一句话+identification+strategy+tasks[3]+scripts[3]+risk_warning。

**回归验证**：修复后205个核心测试全过（persona/personality_types/strategy_advisor/psychology_laws/manipulation_coach/direction_compass/financial_analyzer/task_engine/no_reply_detector/commitment_tracker/deception_detector），0失败。

**已知非bug项（模型能力/环境依赖）**：
1. digital_twin 需要 Ollama 运行才能走L2真实生成；当前走统计兜底
2. RAG/ChromaDB 需要下载ONNX模型（网络依赖）
3. 1.5B小模型人设区分度不足（历史遗留，模型能力天花板）
4. L3云端需要配置API Key
5. 财务安全闸在无收入数据时limit保守（6765），有聊天数据时更精准（E2E=1845），两种情况都feasible=False拦下
