# LoveAI v2 免费 AI 通道全景清单（2026-10-10）

> 本轮（R3.3-43）把所有"免费/零成本"通道一次性梳理清楚：是否要登录、是否要 Key、本机实测可达性、延迟、降级优先级、代码落点。
> 探测环境：Windows PowerShell 5.1，本机网络，探测时间 2026-10-10。

---

## 一、结论速览

| # | 通道 | 真零配置 | 要 Key | 要登录 | 本轮可达 | 延迟 | 优先级 | 代码落点 |
|---|---|---|---|---|---|---|---|---|
| 1 | 本机 Ollama（loveai-qwen05b / loveai-qwen15b） | ✅ | ❌ | ❌ | ⚠️ 进程未起 | 本机回环 <50ms | P1 | `services/llm_gateway.py::_call_l2_ollama` |
| 2 | OpenRouter `:free` 模型 | ❌ | ✅ | ❌ | ✅ HTTP 200 | 726 ms | P2 | `services/free_model_router.py::_fetch_openrouter_free` |
| 3 | NVIDIA NIM 免费端点 | ❌ | ✅ | ❌ | ✅ HTTP 200 | 141 ms | P3 | `services/free_model_router.py::_fetch_nvidia` |
| 4 | browser_ai_hub 14 源 | ❌ | ❌ | ✅（借浏览器 cookie） | unknown（14 站不挨个探） | — | P4 | `services/browser_ai_hub.py` |
| 5 | DesktopAIConnector（Trae/WorkBuddy/Qoder/CodeBuddy） | ❌ | ❌ | ✅（借 IDE 凭据） | unknown | — | P5 | `services/desktop_ai_connector.py` |
| 6 | HF SSH 公开聊天（chat.hf.co） | ❌ | ❌ | ❌ | ❌ ssh exit=255 | — | P99（disabled） | `services/hf_ssh_channel.py` |

**关键提醒**：
- **「免费 ≠ 无 Key」**：OpenRouter、NVIDIA NIM 都是"免费申请 key、按额度免费调用"，不是真零配置。
- **真·零配置只有本机 Ollama**，而且要先 `ollama serve`。
- **HF SSH 通道本轮实测不通**：`ssh whatever@chat.hf.co exit` / `ssh whatever@benchmark-hf.co exit` 均返回 255，已按 R3.3-42 写成 disabled 占位。

## 三、各通道详解

### 1. 本机 Ollama（真·零配置）
- **模型**：`loveai-qwen05b:latest` (491 MB)、`loveai-qwen15b:latest` (1.1 GB)
- **要做什么**：`ollama serve` 常驻；模型名自动 `GET /api/tags` 发现，不硬编码。
- **本轮状态**：进程未起（11434 端口拒连），起服务即通。
- **降级位置**：L2 主后端，L1 拒中文后自动落到这里。

### 2. OpenRouter `:free`（免费≠无 key）
- **目录公开**：`GET https://openrouter.ai/api/v1/models`，按 `pricing.prompt==0 && pricing.completion==0` 或 id 后缀 `:free` 过滤。
- **推理调用**：需要 `llm.free.openrouter_key`，每小时有速率限制。
- **本轮**：目录接口 200 / 726 ms，可达。

### 3. NVIDIA NIM 免费端点（免费≠无 key）
- **有 key**：`GET https://integrate.api.nvidia.com/v1/models`，`Authorization: Bearer <key>`。
- **无 key 兜底**：best-effort 解析 `https://build.nvidia.com/models.md`（正则抽 `vendor/model` id）。
- **本轮**：`/v1/models` 200 / 141 ms，`models.md` 200 / 440 ms，均可达。

### 4. browser_ai_hub 14 源（借登录态）
- 博查 / 密塔 / 天工 / Kimi / 元宝 / 通义 / 智谱 / DeepSeek / 阶跃 / 文心 / 商汤 / 讯飞 / 豆包 / 火山。
- 借用户在浏览器里已登录的账号 cookie，多 profile 轮询，风控命中自动降级 `blocked`。
- **不要 key，但要先登录**。

### 5. DesktopAIConnector（借 IDE 凭据）
- 从本机 Trae / WorkBuddy / Qoder / CodeBuddy 的本地配置里挖 API 凭据，复用用户已订阅的额度。
- 不主动联网申请 key。

### 6. HF SSH 通道（本轮不可用，disabled 占位）
- 目标设想：SSH 到 chat.hf.co / benchmark-hf.co 借宿公共沙箱跑 transformers。
- **实测**：两个域名 SSH 都 255，无公开端点。
- **代码**：`services/hf_ssh_channel.py`，`HFSSHChannel.chat()` 直接 `raise HFSSHChannelDisabled`，在降级链中 priority=99，不参与自动轮询。
- **启用条件**：用户自配 `~/.ssh/config` 跳板 + 跳板上有 python 沙箱 + `pip install paramiko` + config 里 `llm.free.hf_ssh.enabled=true` 并填 host/user/key_path。

## 四、降级优先级链（从高到低）

```
L3 云端 (DeepSeek/豆包/通用 cloud，要 key)
  ↓ 无 key / 失败
free_router (OpenRouter :free → NVIDIA NIM → 本机 ollama)
  ↓ 全部失败
L2 ollama (本机 Qwen，起服务即通)
  ↓ ollama 也没起
L1 (SmolLM2-135M，仅英文/分类，中文主动 raise)
  ↓ 中文必抛
P-10 统计兜底 (LocalStatisticalFallback)
  ↓ 历史样本也没有
规则模板 _rule_reply (你好/谢谢/晚安 等关键词回复)
```

> HF SSH 通道 priority=99，被显式排除在自动降级链外。

## 六、遗留
1. ollama 需要开机自启，否则数字分身会掉回统计兜底。
2. 要真·云端高质量输出仍需配 DeepSeek/豆包 key（代码已就位）。
