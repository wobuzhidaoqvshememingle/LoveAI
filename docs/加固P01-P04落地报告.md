## 三、已存在 vs 本次新增 vs 仍缺

### P-01 证据量→置信上限硬封顶
- 已存在：`confidence.py` 按 raw n_messages 做粗校准（<200→0.55 等），有 0.80 诚实天花板。
- 本次新增：时间衰减 `time_decay_weight/effective_n`、n_eff→上限硬封顶映射、档阶梯、P-04 再降一档；并在 `confidence.py` 轻量接线。
- 仍缺：`engine.py` 尚未把"逐条证据时间戳"汇总成 n_eff 传入 `calibrate(n_eff=...)`（需消息时间衰减聚合，属接线层，未在本次范围内；psychology_laws.py 不在可改范围，未动）。

### P-02 校准口径
- 已存在：`calibration_runner.py` 已有命中率 / ECE(10等宽桶) / 校准因子 / 分桶统计。
- 本次新增：多类 Brier、Murphy 分解（可靠性/分辨度/不确定性）、分辨度有效性判定、`filter_sent_records` 仅已发送口径、ECE 双线 0.10/0.15、`calibration_diagnosis` 汇总。
- 仍缺：尚未把 `calibration_diagnosis` 真正接到 `CalibrationRunner._aggregate` 的输出里（本次为纯函数新增，未改既有跑批输出结构，避免破坏既有 demo）。

### P-03 静默金标准
- 已存在：无（v3.0 无静默抽样机制）。
- 本次新增：`silent_gold_standard.py` 全机制（≥20% 哈希抽样、静默不展示仅存档、两组对照、发送后预填+一键确认）。
- 仍缺：尚未与 `review_loop.py` 的 `record_prediction/settle_latest` 物理打通（本模块用可注入内存存储，真实 DB 接线待封包收尾；review_loop.py 未改）。

### P-04 高压降档 / 先验切换
- 已存在：无。
- 本次新增：触发白名单检测、标准披露措辞、确定性措辞黑名单、剧变期切人群先验标志、非典型个体（约 50 条）放宽 κ + 整体降档。
- 仍缺：触发信号（冲突升级/高情绪唤醒/冷战重启/场景新颖度/分布突变）的上游特征尚未接进来——本模块只提供"给定 flags 后的纯策略动作"，特征提取待与上游引擎对接。
