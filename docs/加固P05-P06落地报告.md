## 0. 标签产出现状（审计结论）

- 标签**主产出点**：`services/evidence_engine/evidence_anchor.py::EvidenceAnchor.bind()`
  产出 `labels` dict（`label_key -> {tendency, confidence, basis, evidence:[{quote,ts,idx,via}], note}`）。
- 聚合入口：`services/evidence_engine/engine.py::EvidenceProfileEngine.analyze()`（第 77-95 行输出 `labels` / `suppressed_labels`）。
- 内层画像另有 `services/persona_analyzer.py`（不在本次可改范围，只读参考），其 attachment/conflict_style 被 engine 消费。
- 版本化现状：`services/model_version_manager.py` 仅管 **LoRA 适配器**版本（create_version/rollback/compare），**不含标签 schema / 标签生成模型双版本**；`services/persona_version.py`（只读）管整个人格快照版本。
- 审计结论：
  - 原标签只绑定 **quote + ts + idx**（有原文引用与时间点），**缺 n（样本量）、区间（interval）、反证（counter_evidence）**。
  - **无** schema 版本、**无**标签生成模型版本、**无**双标签通道一致率、**无** Cohen's κ、**无**冻结/回滚门控。
