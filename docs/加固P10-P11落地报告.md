## 四、模块入口签名与最小调用示例

### P-10：`services/local_statistical_fallback.py`

**主类**：`LocalStatisticalFallback`

```python
from services.local_statistical_fallback import LocalStatisticalFallback

# 最小调用（无历史、无检索器，纯人群先验兜底）
fb = LocalStatisticalFallback()
out = fb.predict(context_features={"scene": "conflict"})

# out 结构：
# {
#   "distribution": {"Y1": 0.078, "Y2": 0.117, ...},   # 概率和=1
#   "labels": {"Y1": "积极推进", ...},
#   "top_reaction": "Y4",
#   "top_prob": 0.216,
#   "level": "极低",                  # 证据不足时为"极低"
#   "evidence_insufficient": True,   # 空历史 -> True
#   "n_history": 0,
#   "n_retrieved": 0,
#   "annotation": "无生成模型，仅统计预测",
#   "context_used": {"scene": "conflict"},
#   "shrunk": True,
# }

# 便捷文本输出（给 UI / gateway 接线用）
text = fb.predict_top_text({"scene": "daily"})
# "[无生成模型，仅统计预测] 中性"
```

**带历史 + 检索器的完整调用**：
```python
def my_retriever(ctx):
    if ctx.get("scene") == "conflict":
        return [("Y5", 3.0), ("Y6", 2.0)]
    return []

fb = LocalStatisticalFallback(
    history_counts={"Y1": 5, "Y2": 8, "Y3": 12, "Y4": 20,
                    "Y5": 6, "Y6": 10, "Y7": 4},   # 65 条历史
    retriever=my_retriever,
    population_prior=None,              # 用默认人群先验
    prior_strength=20.0,
    min_evidence=10,
)
out = fb.predict({"scene": "conflict"})
# out["evidence_insufficient"] == False
# out["level"] in ("低","中","极低")
```

**供 `llm_gateway.py` 降级接线的建议入口**（由上级代理统一接线）：
```python
# 在 llm_gateway 的所有生成模型尝试失败后：
from services.local_statistical_fallback import LocalStatisticalFallback
fb = LocalStatisticalFallback(history_counts=your_store.load_counts())
return fb.predict(context_features=your_ctx)
```

**纯函数**（可独立单测）：
- `normalize_probs(probs: dict) -> dict`
- `shrink_counts(counts: dict, prior: dict|None=None, strength: float=20.0) -> dict`
- `align_to_categories(dist: dict, categories: tuple=REACTION_CATEGORIES) -> dict`

### P-11：`services/shadow_eval.py`

**影子三阶段门控**：
```python
from services.shadow_eval import ShadowGate, STAGE_FULL

gate = ShadowGate(baseline_p=0.20, current_stage=0)

# 跑一段时间静默子样本后评估：
r = gate.can_advance(hits=50, n=100)
if r["can_advance"]:
    gate.advance()   # 0 -> 1
    # 再跑，再评：
    r2 = gate.can_advance(hits=60, n=100)
    if r2["can_advance"]:
        gate.advance()   # 1 -> 2（全功能）
```

**合成/对抗数据隔离**：
```python
from services.shadow_eval import (
    tag_record, split_by_source, assert_accuracy_pool_only_real,
    SOURCE_REAL, SOURCE_SYNTHETIC, SOURCE_ADVERSARIAL,
)

records = [
    tag_record({"text": "真人消息1", "hit": True}, SOURCE_REAL),
    tag_record({"text": "合成画像", "hit": True}, SOURCE_SYNTHETIC),
    tag_record({"text": "对抗扰动", "hit": False}, SOURCE_ADVERSARIAL),
]
pool = split_by_source(records)
# pool[SOURCE_REAL] 才能进对外准确率
assert_accuracy_pool_only_real(pool[SOURCE_REAL])   # 通过
# assert_accuracy_pool_only_real(pool[SOURCE_SYNTHETIC])  # 抛 ValueError
```

**需求级验收三项**：
```python
from services.shadow_eval import (
    check_confidence_discrimination,
    check_retrieval_ablation,
    check_regret_rate,
)

# ① 置信档区分度
r1 = check_confidence_discrimination(
    low_conf_errors=80, low_conf_n=200,
    high_conf_errors=20, high_conf_n=200,
)
# r1["passed"] == True

# ② 检索消融
r2 = check_retrieval_ablation(
    hits_with=150, n_with=200,
    hits_without=100, n_without=200,
)
# r2["passed"] == True

# ③ 1周回访后悔率
r3 = check_regret_rate(regrets=3, n=30, threshold=0.20)
# r3["passed"] == True
```
