> 日期：2026-10-10

> 原则：本地规则能搞定的本地跑（快、便宜），复杂推理走云端大模型；LoveAI 主体性（策略引擎 + 人物侧写）不动。

## 一、六层体系总览（用户给定的完整框架）

整套体系按"人 → 关系 → 改变 → 判断 → 落地 → 验证"六层组织，LoveAI 每层都有落点：

| 层 | 内容 | LoveAI 落点 | 跑在哪 |
|---|---|---|---|
| 第一层 认识人 | 人格/发展/认知/情绪/社会/进化/变态临床/神经科学/内分泌/社会学/人类学/哲学 | 知识库 + 云端大模型推理时调用的理论背景 | 云端（知识型） |
| 第二层 理解关系 | 依恋理论、爱情三角、投资模型、社会交换/渗透、认知失调/归因、拟剧理论、进化择偶、性别研究、线上亲密关系 | persona_analyzer 的依恋/权力/投入维度 + psychology_laws 定律库 | 本地已有 + 云端补充 |
| 第三层 改变人 | 精神分析/CBT/DBT/ACT/家庭系统/EFT/Gottman/MI/TTM/自我决定论/福格行为模型 | 本次新增的**双路线策略**（修复路线 / 反制路线）+ 任务拆解，话术风格对齐 NVC / Gottman 修复 / MI 亮底线 | 本地数据 + 云端细化 |
| 第四层 判断人 | 大五 NEO-PI-R、黑暗三联征、成人依恋、情绪调节 DERS、微表情/非语言编码、计算人格学；MBTI/九型/DISC 作为"巴纳姆效应沟通工具" | **本次新建 psychology_pattern_engine 本地规则引擎**（40 个模式），复杂模糊判断升级云端 | 本地为主，模糊带/高风险升级云端 |
| 第五层 落地功夫 | 非暴力沟通、冲突修复、5:1 正负比、五种爱语、边界、正念、GROW 教练 | **三档话术库 + 每日任务清单 + 信念桥接（belief_bridge）** | 本地数据 |
| 第六层 方法论 | RCT、元分析、纵向追踪、质性研究、混合方法、可重复性 | pytest 回归 + 后续 A/B 验证的方向说明，不在本次代码范围内 | 工程验证 |

一句话：**第四层是本次代码主战场，第五层是本次话术/任务主战场，第一二三层是云端推理的知识弹药，第六层是测试和验证门槛。**

## 二、现状盘点（已有什么 / 缺什么）

盘点详情见 `docs/_心理学现状盘点-20261010.md`。结论：

- 对照 40 个目标模式：**已覆盖 13 / 部分覆盖 18 / 缺失 9**。
- 已覆盖：自恋、焦虑/回避型依恋、煤气灯、冷暴力沉默、被动攻击、初识/暧昧/热恋、权力上/下/同层、承诺不兑现。
- 原缺失：大五四维（宜人性/尽责性/外向性/开放性）、回吸 Hoover、飞猴 Flying Monkeys、Satir 讨好/超理智/打岔。
- 最成熟的三块老资产：`persona_analyzer.py` 的依恋+黑暗三联征词表、`deception_detector.py` 的统计漂移底座、`personality_strategy.py` 的 14 人格签名库。

老模块的定位：persona_analyzer 是**纵向人物侧写**（一个人聊三个月的数据画像），本次新引擎是**横向即时扫描**（扔进来一段聊天窗口，秒级告诉你命中哪些模式、该说什么话）。两者不互相替代，新引擎不 import 老重模块，保持秒级启动、零依赖。

### 3.1 新文件清单

| 文件 | 作用 |
|---|---|
| `services/psychology_pattern_engine.py` | 本地规则检测引擎（纯标准库，不碰 PySide6，数据文件缺失不崩） |
| `tests/test_psychology_pattern_engine.py` | 引擎测试，10 个用例全绿 |

| `knowledge/belief_bridge.json` | **信念桥接库**：星座/MBTI/八字/塔罗/风水/属相/手相/通用 8 套借壳话术 |
| `docs/心理学全维度判断体系-20261010.md` | 本文档 |

备份均已按规矩做：`psychology_patterns.json.bak`、`psychology_pattern_engine.py.bak`、`test_psychology_pattern_engine.py.bak`。**没有改动任何已有核心文件**（策略引擎、人物侧写一行未动）。

### 3.2 引擎接口

```python
from services.psychology_pattern_engine import PsychologyPatternEngine, analyze_messages

eng = PsychologyPatternEngine()
eng.scan_text("我什么时候说过，是你想多了")        # 单条消息命中列表
result = eng.analyze_window([...最近聊天消息...])  # 窗口聚合分析
eng.get_scripts("manip_gaslighting", "hard")       # 取某模式某档话术
```

`analyze_window` 返回：
- `summary`：人话总结，点出最值得注意的 1-3 个模式；
- `hits`：每个命中模式带 confidence(low/medium/high)、分数、证据原文、建议档位、三档话术、**双路线策略**、**4 条落地任务**、推荐路线；
- `needs_cloud_review`：是否该升级云端大模型复核；
- `stage_guess`：关系阶段猜测。

### 3.3 打分与升级规则（本地 vs 云端分工）

- 本地：strong 关键词命中 +2 分、soft 关键词 +1 分，同短语同消息去重，跨窗口累加。
- confidence：≥5 高 / 2-4 中 / 1 低（低不进 hits）。
- **needs_cloud_review = True（必须交云端大模型）** 的三种情况：
  1. 分数卡在 3-4 分的模糊带——像又不确定，本地规则不敢定性；
  2. 互斥模式同时高分（焦虑型↔回避型、对方上位↔同层）——需要上下文推理；
  3. 高风险模式命中（创伤反应 trauma_reaction、冷暴力要挟 power_coldblackmail、抛弃贬低 manip_discard）——本地只提示，不替用户下结论。
- 其余情况：本地规则直接给结果，不烧云端 token。

## 四、40 个模式全景（第四层）

七大类，每类后面括号里是覆盖状态变化：

- **人格（8）**：自恋、马基雅维利、精神病态、神经质、宜人性、尽责性、外向性、开放性（后四个本次从零补词表）
- **依恋（4）**：焦虑型、回避型、安全型、恐惧型
- **操纵（8）**：煤气灯、DARVO 反咬、Hoover 回吸（新）、冷暴力沉默、三角测量、爱意轰炸、抛弃贬低、飞猴（新）
- **沟通（5，Satir 五姿态）**：被动攻击、指责型、讨好型（新）、超理智型（新）、打岔型（新）
- **关系阶段（6）**：初识、暧昧、热恋、矛盾、倦怠、修复
- **权力（5）**：对方上位、对方下位、同层、冷暴力要挟、承诺不兑现
- **其他（4）**：创伤反应、情绪剧烈波动、低共情、边界感弱

每个模式的 `signals.keywords` 是中国人真实会说出口的原话（如煤气灯："我什么时候说过""你记错了吧""你太敏感了"），不是抽象概念词。

## 五、闭环：识别 → 判断 → 策略 → 任务 → 话术

每个模式四件套齐全，举个真实例子（焦虑型依恋 + 冷暴力沉默）：

1. **识别**：窗口里命中 `att_anxious`（+2/句）和 `manip_silent_treatment`，confidence=high。
2. **判断**：推荐路线 = `repair_route`（还想好好谈的关系，给安全感但不追太紧）。
3. **策略（双路线）**：
   - 修复路线 steps：她问你在哪你拍照回 → 焦虑时给具体时间点 → 分享轻松日常不提感情 → 聊她感兴趣的话题引导她主动说；when_to_stop = 你已经连续主动一周她依旧冷脸，转反制。
   - 反制路线 steps：第一次越界温和提醒 → 第二次亮底线 → 第三次断供抽身；when_to_hard / when_to_soft 写清节奏。
4. **任务（拆到每天）**：
   - 今天："今晚她再问'你在哪跟谁'，你拍张照回一句"
   - 明天/后天/本周：各一条具体动作。
5. **话术（三档，可直接复制粘贴）**：
   - 温和："今天看到一个东西突然想到你了"
   - 中等："你今天好像有点累，要不要早点休息？"
   - 强硬："你不回消息我也不追了，你想聊的时候我都在"

话术风格背后有依据但不甩名词：温和档 = NVC（观察→感受→需要），中等档 = Gottman 修复对话（明确立场+具体替代做法），强硬档 = MI 式亮底线（点破+最后通牒+抽身动作，不人身攻击）。

## 六、信念桥接（借力打力）

新增 `knowledge/belief_bridge.json`：用户自己信星座/MBTI/八字/塔罗/风水/属相/手相时，LoveAI 不拆台（不说"这是骗人的"），先接住他的框架，再把建议翻译成他听得进去的话。

每套体系含：opener（接住框架的话 5-6 条）、bridge（顺势搭桥 8 条）、advice_templates（10 条白话建议→该体系语言版本，覆盖主动联系/好好沟通/划边界/别冷战/认真约会/给空间/观察人品/别急表白）。

本质：共情先行、引导在后，用他信的壳装我们的药；不搞真迷信，不收费算命，不预测吉凶吓人。
