# LoveAI 心理学参考体系筛选清单

> 日期：2026-10-10
> 主线：恋爱 / 沟通 / 依恋 / 操纵 / 人格
> 配套代码：`services/psych_catalog.py`（结构化 dict，供"关于/理论依据"页展示）
> 配套测试：`tests/test_psych_catalog.py`

---

## 一、筛选原则

LoveAI 是"帮用户把一段关系走明白"的产品，不是临床心理诊所，也不是心理学教材。
因此只保留**能直接转化成"下一步做什么/说什么"**的理论；纯学术解释、纯临床诊断、
纯管理/教育场景的条目降级为"参考但不主用"。

- **主用**：理论 → 维度判断 → 策略/任务/话术，链条完整。
- **参考**：知道有这回事，能在话术中打个比方，但不参与 dims 匹配和任务派发。

## 二、主用理论（13 条）

### 1. 依恋理论（Bowlby / Ainsworth）
- **为什么留**：成人依恋四型（安全/焦虑/回避/恐惧）是 LoveAI 判断对方行为动机的第一把钥匙。焦虑型要"稳定回应"，回避型要"给空间"，策略完全相反。
- **在 LoveAI 哪个模块用**：`persona_analyzer._analyze_attachment` 三维评分；`strategy_advisor._ATTACHMENT_MAP` 策略矩阵；`psychology_laws.attachment_foundational`。
- **对应代码文件**：`services/persona_analyzer.py`

### 2. 大五人格（Costa & McCrae，NEO-PI-R）
- **为什么留**：OCEAN 是人格稳定性、宜人性、尽责性的学术底座。LoveAI 用神经质（情绪波动）和宜人性（共情/合作）做代理指标，其余三维在 `diagnostic_report.py` 补。
- **在 LoveAI 哪个模块用**：`personality_strategy` 14 人格签名；`persona_analyzer` 情绪模式 volatility。
- **对应代码文件**：`services/personality_strategy.py`

### 3. DSM-5 人格障碍（NPD / BPD 为主）
- **为什么留**：识别自恋型/边缘型等病理性关系模式，是 LoveAI"反制路线"和危机分级的依据。不是给人贴标签，是判断"这段关系需要硬边界还是软修复"。
- **在 LoveAI 哪个模块用**：`personality_strategy.npd / bpd`；`persona_analyzer._DARK_TRIAD_SIGNALS`；`digital_twin` 系统提示里硬编码的 NPD/BPD 语气规则。
- **对应代码文件**：`services/personality_strategy.py`

### 4. Gottman 婚姻研究体系
- **为什么留**：四骑士（批评/鄙视/辩护/冷战）、5:1 正负比、情感投标、爱情地图、爱情大厦——是长期关系满意度的金标准，也是 LoveAI 冲突修复话术的风格底座。
- **在 LoveAI 哪个模块用**：`psychology_laws` 里 `gottman_four_horsemen / gottman_5to1_ratio / emotional_bids / love_maps / sound_relationship_house` 五条；`strategy_advisor` 冲突矩阵。
- **对应代码文件**：`services/psychology_laws.py`

### 5. 爱情三角理论（Sternberg）
- **为什么留**：亲密/激情/承诺三要素定位当前关系是"喜欢/迷恋/空洞/浪漫/伴侣/圆满"，决定阶段是该升温、该谈承诺还是该补亲密感。
- **在 LoveAI 哪个模块用**：`psychology_laws.sternberg_triangle`；`persona_analyzer._analyze_relationship_stage`。
- **对应代码文件**：`services/psychology_laws.py`

### 6. Rusbult 投资模型
- **为什么留**：满意度 + 替代质量 + 投入量共同决定承诺度。解释"为什么不幸福也不分手"，是沉没成本、反制路线、引导对等投入的理论依据。
- **在 LoveAI 哪个模块用**：`persona_analyzer.investment_balance`；`psychology_laws.sunk_cost`。
- **对应代码文件**：`services/persona_analyzer.py`

### 7. 认知失调（Festinger）
- **为什么留**：解释人为何为自己投入过的人/事辩护。是"越付出越爱"和反 PUA 时打破自我辩护的入口——不改变事实，只改变他对事实的解释。
- **在 LoveAI 哪个模块用**：`psychology_laws.cognitive_dissonance`；`manipulation_coach` 反制话术。
- **对应代码文件**：`services/psychology_laws.py`

### 8. 社会渗透理论（Altman & Taylor，自我暴露）
- **为什么留**：关系亲密度 = 自我暴露的广度 + 深度。是判断"我们到底熟到哪一步"的核心指标，避免刚认识就掏心窝子或在一起三年还在聊表面。
- **在 LoveAI 哪个模块用**：`psychology_laws.self_disclosure_law`；`persona_analyzer` 关系阶段。
- **对应代码文件**：`services/psychology_laws.py`

### 9. 相互依赖理论（Kelley & Thibaut）
- **为什么留**：关系是双方结果矩阵的博弈。对等投入、非零和是判断"这段关系值不值得继续"的底层框架，避免单方面付出还自我感动。
- **在 LoveAI 哪个模块用**：`psychology_laws.non_zero_sum / reciprocity_principle`；`persona_analyzer.investment_balance`。
- **对应代码文件**：`services/psychology_laws.py`

### 10. 非暴力沟通（Rosenberg，NVC）
- **为什么留**：观察-感受-需要-请求四步法是 LoveAI 温和档话术的风格底座，避免指责、冷战、翻旧账。
- **在 LoveAI 哪个模块用**：`strategy_advisor` recommended 话术；`tutorial_engine` 分步教程。
- **对应代码文件**：`services/strategy_advisor.py`

### 11. 煤气灯效应（Gaslighting）
- **为什么留**：系统性否定对方现实感是 PUA/NPD 的核心手段。LoveAI 用 `_DEFENSIVE_SIGNALS`（否定现实/煤气灯贬低）直接识别并出反制，不是靠用户自己后知后觉。
- **在 LoveAI 哪个模块用**：`persona_analyzer._DEFENSIVE_SIGNALS`；`manipulation_coach`；`psychology_laws.gaslighting_effect`。
- **对应代码文件**：`services/manipulation_coach.py`

### 12. PUA 五大流派
- **为什么留**：拆解打压、冷热推拉、爱轰炸、间歇性强化等手段，是 LoveAI 反识别与"别变成那样"的反面教材。不是教用户去 PUA，是教用户认出自己正在被 PUA。
- **在 LoveAI 哪个模块用**：`persona_analyzer._DARK_TRIAD_SIGNALS`；`deception_detector.EARLY_PROMISE/GIFT`；`psychology_laws.intermittent_reinforcement / scarcity_principle`。
- **对应代码文件**：`services/persona_analyzer.py`

### 13. 路径依赖（David / Arthur）
- **为什么留**：关系一旦形成固定互动模式（追逃/冷战/讨好），单靠"想通了"改不动；必须靠新任务、新行为打断惯性。是 LoveAI 为什么一定要派任务而不是只出分析的原因。
- **在 LoveAI 哪个模块用**：`task_engine` 打断惯性任务；`psychology_laws.loss_aversion / sunk_cost`。
- **对应代码文件**：`services/task_engine.py`

## 三、参考但不主用（6 条）

### A. 精神分裂 / 双相情感障碍细节（DSM-5 临床精神病学）
- **为什么不留**：LoveAI 不做临床诊断。只在 `detect_self_harm_risk` 等安全门上做风险提示，不替代就医。
- 对应 law_id：`werther_effect`（自杀模仿，安全门用）。

### B. 发展心理学童年期理论（皮亚杰/埃里克森早期阶段）
- **为什么不留**：成人依恋理论已经覆盖"童年经历如何影响成年关系"。童年期细节不直接服务于"这段关系下一步怎么走"，讲多了反而让用户陷入原生家庭归因而停止行动。
- 无对应 law_id。

### C. 工业组织心理学（领导力/员工动机）
- **为什么不留**：社交层级沟通法则、名片效应等带 I-O 色彩的条目，与亲密关系场景弱相关。仅在话术修辞里借用，不进主策略。
- 对应 law_id：`social_hierarchy_comm`。

### D. 教育心理学（皮格马利翁/过度理由）
- **为什么不留**：教师对学生的期待效应、外部动机挤出效应，在恋爱场景只做弱映射（"你越夸他他越好"），不做主用理论。
- 对应 law_id：`pygmalion_effect / overjustification`。

### E. 长久爱情神经科学（VTA/尾状核/多巴胺）
- **为什么不留**：神经科学结论用来做科普解释很好（"为什么三年后激情会变淡"），但 LoveAI 本地规则拿不到脑电数据，只能作为注释，不参与判定。
- 对应 law_id：`long_term_love_neuroscience`。

### F. 民间/管理类定律（墨菲/蝴蝶/木桶/二八/手表/鸟笼/飞轮/鲶鱼）
- **为什么不留**：修辞价值大于预测价值。不在主策略命中表，仅在话术里做比喻，不参与 dims 匹配。
- 代表 law_id：`murphy_law / butterfly_effect / bucket_effect / pareto_8020 / two_watches_effect / birdcage_logic / flywheel_effect / catfish_effect`。
