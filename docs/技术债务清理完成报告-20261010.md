## 四、关键修正

### 4.1 psychology_laws.py 不是死代码！

**之前误判**：盘点报告说"psychology_laws.py 三级断链，无人引用"。

**实际验证**：
- `services/strategy_advisor.py:30` 直接 `from services import psychology_laws`
- `:1316` 调用 `psychology_laws.match_laws(persona, relation_stage, dims)`
- `:1333` 调用 `psychology_laws.law_reasoning_lines(hits)`
- `:867,876` 使用 `LAW_TIP_PURPOSES` 和 `LAW_MISUSE_WARNINGS`

**结论**：psychology_laws.py（1831 行，131 KB，91+ 条心理学定律）正在主链路工作，**没有被清理**。

**误判原因**：AST BFS 脚本第一版没正确处理 `from services import psychology_laws` 这种"从包 import 子模块"的形式，导致误判为死代码。已修正。
