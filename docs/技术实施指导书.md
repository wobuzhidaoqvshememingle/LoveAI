## 一、技术选型（定死，不换）

| 层 | 技术 | 选型理由 |
|----|------|----------|
| 桌面框架 | **PySide6 (Qt6)** | 现有项目基础，QWebEngineView+QWebChannel成熟 |
| 前端 | **HTML/CSS/JS（单页）** | 现有ui.html基础，烫金暗色风，QWebEngine渲染 |
| 桥接 | **QWebChannel** | Python↔JS双向通信，**禁止pywebview**（旧版崩溃根源） |
| 微信自动化 | **pywechat127** | pure UIA，支持微信4.1+，不注入不Hook，有Monitor/AutoReply/Messages完整API |
| 大模型 | **OpenAI兼容客户端 + llama.cpp** | 云端API + 本地GGUF模型（已有qwen2.5-0.5b-q4_k_m.gguf） |
| 数据库 | **SQLite + SQLAlchemy** | 单文件，已有unified_search.db可复用 |
| 向量库 | **ChromaDB** | 已有data/chroma_db，直接复用 |
| 语音识别 | **faster-whisper** | 本地运行，中文好 |
| OCR | **RapidOCR** | 本地，无需Tesseract |
| 图像生成 | 云端API（Stability/豆包） | 本地图像生成质量差，v2.0只用云端 |
| 打包 | **PyInstaller onedir** | 现有打包经验，模型不打包（单独下载） |

### 为什么不换Electron
- 现有PySide6代码资产（qt_gui.py 43KB、api_bridge.py 32KB的66个API设计）可复用
- 现有模型/知识库/立绘资产全是Python生态
- Electron打包体积大（200MB+），Python生态AI库集成麻烦
- 用户已有PyInstaller打包流程

### 2.2 关键设计决策

**决策1：无HTTP服务器，全QWebChannel直连**
- 旧版搞出了多余的http_server.py（8899端口），和桌面端架构不匹配
- v2.0：所有Python功能通过QWebChannel的@Slot暴露给JS，JS直接调用，零网络开销
- 后台线程通过信号（Signal）通知UI更新

**决策2：单Bridge多窗口**
- 所有QWebEngineView共享同一个ApiBridge实例
- 避免多个bridge状态不同步
- 桌宠/悬浮窗/主窗的状态变化通过bridge的信号广播到所有窗口

**决策3：懒加载+自动卸载**
- 启动时只加载：配置、数据库连接、UI
- 大模型：第一次调用时才加载，5分钟空闲自动卸载
- 微信监听：用户开启后才启动pywechat连接
- 解决旧版CPU 143%问题

**决策4：服务层与UI层完全分离**
- services/ 下的模块不import任何PySide6（除了Signal定义）
- 可独立单元测试
- UI层只通过bridge调用服务层

**决策5：引导闭环是核心业务流程**
- 所有功能围绕"目的→任务→教程→执行→反馈→推进"六步闭环设计
- task_engine（发什么动作）+ tutorial_engine（教怎么干）是双核心引擎
- 回复建议是教程在执行层的实时台词生成，不是独立功能
- 任何新功能必须能回答"它在闭环的哪一步"，否则不做

## 四、QWebChannel 桥接规范（核心，解决旧版崩溃）

### 4.1 Bridge 结构

```python
# app/bridge.py
from PySide6.QtWebChannel import QWebChannel
from PySide6.QtCore import QObject, Slot, Signal

class ApiBridge(QObject):
    """统一暴露给JS的API层。所有窗口共享同一个实例。"""

    # 信号：后台事件推送到所有JS窗口
    new_message = Signal(dict)           # 新微信消息
    analysis_ready = Signal(dict)        # 分析结果就绪
    task_updated = Signal(dict)          # 任务变化
    affection_changed = Signal(dict)     # 好感度变化
    medal_unlocked = Signal(dict)        # 勋章解锁
    person_switched = Signal(dict)       # 对象切换
    wechat_status = Signal(dict)         # 微信连接状态

    def __init__(self, services: dict):
        super().__init__()
        self.services = services  # 所有服务实例

    # === 聊天分析 ===
    @Slot(str, result=str)
    def analyze_chat(self, chat_text):
        return self.services['chat_analyzer'].analyze(chat_text)

    @Slot(str, str, result=str)
    def send_reply_to_wechat(self, text):
        return self.services['wechat'].fill_text(text)

    # === 人物档案 ===
    @Slot(result=str)
    def list_persons(self):
        return json.dumps(self.services['person'].list_all())

    @Slot(str, result=str)
    def get_person(self, person_id):
        return json.dumps(self.services['person'].get(person_id))

    # ... 共60+个Slot，按功能域分组
```

### 4.2 JS 端封装

```javascript
// ui/js/bridge.js
let bridge = null;

function initBridge() {
    new QWebChannel(qt.webChannelTransport, function(channel) {
        bridge = channel.objects.apiBridge;

        // 注册信号监听
        bridge.new_message.connect(function(data) {
            handleNewMessage(JSON.parse(data));
        });
        bridge.analysis_ready.connect(function(data) {
            handleAnalysisReady(JSON.parse(data));
        });
        // ... 其他信号
    });
}

// 调用封装（带超时和错误处理）
async function call(method, ...args) {
    return new Promise((resolve, reject) => {
        if (!bridge) { reject(new Error('Bridge not ready')); return; }
        const timeout = setTimeout(() => reject(new Error('Timeout')), 30000);
        bridge[method](...args, function(result) {
            clearTimeout(timeout);
            try { resolve(JSON.parse(result)); }
            catch(e) { resolve(result); }
        });
    });
}
```

### 4.3 铁律
- **禁止在JS中使用 pywebview.api.xxx**——所有调用必须走 `bridge.xxx()`
- 所有@Slot返回值统一为JSON字符串（JS端parse）
- 耗时操作（大模型调用）在后台线程执行，完成后通过Signal推送结果，不阻塞UI
- Bridge方法只做参数校验和服务调用，不写业务逻辑

### 5.1 微信服务（wechat_service.py）

**封装 pywechat127，解决旧版自写UIA不稳定的问题。**

```python
import threading
from pyweixin import Navigator, Monitor, Messages, Tools

class WeChatService:
    def __init__(self, signals, config):
        self.signals = signals
        self.config = config
        self.connected = False
        self.listener_thread = None
        self.running = False
        self.current_person = None
        self.last_msg_hash = set()

    def connect(self):
        """连接微信，检测版本"""
        try:
            info = Tools.about_weixin()
            self.connected = True
            self.signals.wechat_status.emit({'status': 'connected', 'info': info})
            return True
        except Exception as e:
            self.signals.wechat_status.emit({'status': 'error', 'error': str(e)})
            return False

    def get_current_chat_person(self) -> str:
        """获取当前聊天窗口对方昵称（用于自动切换对象）"""
        # pywechat127 提供窗口标题获取
        pass

    def start_listener(self):
        """启动后台监听线程"""
        if self.running:
            return
        self.running = True
        self.listener_thread = threading.Thread(target=self._listen_loop, daemon=True)
        self.listener_thread.start()

    def _listen_loop(self):
        """监听循环：每1.5秒检查一次新消息"""
        while self.running:
            try:
                person = self.get_current_chat_person()
                if person and person != self.current_person:
                    self.current_person = person
                    self.signals.person_switched.emit({'wechat_nickname': person})

                # 获取新消息（pywechat127的Monitor或Messages接口）
                new_msgs = self._get_new_messages()
                for msg in new_msgs:
                    msg_hash = hash(msg['content'] + msg['time'])
                    if msg_hash not in self.last_msg_hash:
                        self.last_msg_hash.add(msg_hash)
                        self.signals.new_message.emit(msg)

                # 控制last_msg_hash大小
                if len(self.last_msg_hash) > 500:
                    self.last_msg_hash = set(list(self.last_msg_hash)[-200:])

            except Exception as e:
                pass  # 监听出错不崩溃，下次重试
            time.sleep(1.5)

    def fill_text(self, text: str) -> bool:
        """将文本填入微信对话框（不自动发送）"""
        try:
            # 校验当前窗口
            person = self.get_current_chat_person()
            # pywechat127 Messages.send_text 或直接操作输入框
            Messages.send_text(text)  # 具体API以pywechat127文档为准
            return True
        except Exception as e:
            # 降级：剪贴板+Ctrl+V
            import pyperclip
            pyperclip.copy(text)
            # 模拟Ctrl+V
            return False

    def stop_listener(self):
        self.running = False
```

**关键**：
- 监听频率1.5秒（旧版可能太频繁导致CPU高）
- 消息去重用hash集合，上限500
- 监听线程daemon=True，不阻塞退出
- pywechat127失败时降级为剪贴板+模拟按键

### 5.2 大模型网关（llm_gateway.py）

**三级路由 + Prompt模板管理 + 懒加载 + 自动卸载。**

```python
import time, json
from openai import OpenAI

class LLMGateway:
    def __init__(self, config, signals):
        self.config = config
        self.signals = signals
        self.local_model = None      # llama.cpp模型实例
        self.local_loaded = False
        self.last_call_time = 0
        self.unload_timeout = 300    # 5分钟空闲卸载

    def chat(self, system_prompt: str, user_prompt: str,
             complexity: str = 'auto', temperature=0.7, max_tokens=2000) -> str:
        """
        统一聊天接口。
        complexity: simple(L1) / medium(L2) / complex(L3) / auto(自动判断)
        """
        # 自动判断复杂度
        if complexity == 'auto':
            complexity = self._judge_complexity(user_prompt)

        # 路由选择
        if complexity == 'simple':
            return self._call_local(system_prompt, user_prompt, temperature, max_tokens)
        elif complexity == 'medium' and self.config.offline_mode:
            return self._call_local(system_prompt, user_prompt, temperature, max_tokens)
        else:
            try:
                return self._call_cloud(system_prompt, user_prompt, temperature, max_tokens)
            except Exception as e:
                # 云端失败降级本地
                return self._call_local(system_prompt, user_prompt, temperature, max_tokens)

    def _call_cloud(self, system_prompt, user_prompt, temperature, max_tokens):
        client = OpenAI(api_key=self.config.api_key, base_url=self.config.api_base)
        resp = client.chat.completions.create(
            model=self.config.model,
            messages=[{"role":"system","content":system_prompt},
                      {"role":"user","content":user_prompt}],
            temperature=temperature, max_tokens=max_tokens
        )
        self.last_call_time = time.time()
        return resp.choices[0].message.content

    def _call_local(self, system_prompt, user_prompt, temperature, max_tokens):
        self._ensure_local_loaded()
        # llama.cpp Python绑定调用
        output = self.local_model.create_chat_completion(
            messages=[{"role":"system","content":system_prompt},
                      {"role":"user","content":user_prompt}],
            temperature=temperature, max_tokens=max_tokens
        )
        self.last_call_time = time.time()
        return output['choices'][0]['message']['content']

    def _ensure_local_loaded(self):
        """懒加载本地模型"""
        if not self.local_loaded:
            from llama_cpp import Llama
            self.local_model = Llama(
                model_path=self.config.local_model_path,
                n_ctx=4096, n_threads=4, verbose=False
            )
            self.local_loaded = True

    def auto_unload_check(self):
        """定时调用：5分钟无调用卸载本地模型"""
        if self.local_loaded and time.time() - self.last_call_time > self.unload_timeout:
            del self.local_model
            self.local_model = None
            self.local_loaded = False

    def load_prompt(self, template_name: str, **kwargs) -> str:
        """加载Prompt模板并注入变量"""
        path = f"prompts/{template_name}.txt"
        with open(path, 'r', encoding='utf-8') as f:
            template = f.read()
        for k, v in kwargs.items():
            template = template.replace(f"{{{{{k}}}}}", str(v))
        return template

    def _judge_complexity(self, text: str) -> str:
        """简单规则判断复杂度，避免每次都调云端"""
        if len(text) < 20:
            return 'simple'
        if any(kw in text for kw in ['分析', '为什么', '怎么办', '预测', '模拟']):
            return 'complex'
        return 'medium'
```

```python
class RAGService:
    def __init__(self, fts_db_path, chroma_path):
        self.fts = self._init_fts(fts_db_path)
        self.chroma = self._init_chroma(chroma_path)

    def search(self, query: str, top_k=5) -> list:
        """混合检索：FTS5 + 向量 → 去重 → 重排序"""
        # FTS5全文检索
        fts_results = self._fts_search(query, top_k=5)
        # 向量语义检索
        vec_results = self._vector_search(query, top_k=5)
        # 合并去重
        merged = {}
        for r in fts_results + vec_results:
            key = r['content'][:50]  # 用前50字去重
            if key not in merged:
                merged[key] = r
            else:
                merged[key]['score'] = max(merged[key]['score'], r['score'])
        # 按分数排序
        results = sorted(merged.values(), key=lambda x: x['score'], reverse=True)
        return results[:top_k]

    def _fts_search(self, query, top_k):
        # SQLite FTS5 MATCH查询
        cursor = self.fts.execute(
            "SELECT content, rank FROM knowledge_fts WHERE knowledge_fts MATCH ? LIMIT ?",
            (query, top_k)
        )
        return [{'content': r[0], 'score': 1.0/(r[1]+1), 'source': 'fts'} for r in cursor]

    def _vector_search(self, query, top_k):
        results = self.chroma.query(query_texts=[query], n_results=top_k)
        return [{'content': d, 'score': 1.0/(i+1), 'source': 'chroma'}
                for i, d in enumerate(results['documents'][0])]
```

```python
            "SELECT * FROM tasks WHERE person_id=? AND status='in_progress'",
            (person_id,)).fetchall()

                    # 检查是否所有步骤完成
                    if self._is_all_steps_done(task['id']):
                        self._complete(task, 'keyword')
            # 2. 分步任务：检测当前步骤的完成关键词
            elif task.get('steps_json'):
                current = self._get_current_step(task['id'])
                if current and current.get('complete_keywords'):
                    if any(k in message for k in current['complete_keywords']):
                        self._advance_step(task['id'])
                        if self._is_all_steps_done(task['id']):
                            self._complete(task, 'steps_done')

    def _get_current_step(self, task_id: str) -> dict:
        """获取任务当前分步"""
        task = self.db.execute("SELECT * FROM tasks WHERE id=?", (task_id,)).fetchone()
        if not task or not task.get('steps_json'):
            return None
        steps = json.loads(task['steps_json'])
        idx = task['current_step']
        return steps[idx] if idx < len(steps) else None

    def _advance_step(self, task_id: str):
        """推进任务到下一步"""
        self.db.execute(
            "UPDATE tasks SET current_step=current_step+1 WHERE id=?", (task_id,))

    def _is_all_steps_done(self, task_id: str) -> bool:
        """检查任务是否全部分步完成"""
        task = self.db.execute("SELECT * FROM tasks WHERE id=?", (task_id,)).fetchone()
        if not task or not task.get('steps_json'):
            return True  # 没有分步的任务，直接算完成
        steps = json.loads(task['steps_json'])
        return task['current_step'] >= len(steps)

    def _complete(self, task, reason):
        """完成任务→奖励→推进引导闭环（⑥节奏推进）"""
        self.db.execute("UPDATE tasks SET status='completed',completed_at=datetime('now') WHERE id=?",
                        (task['id'],))
        if task.get('affection_reward'):
            self.affection.add_bonus(task['person_id'], task['affection_reward'])
        self.signals.task_updated.emit({'task': task, 'event': 'completed'})
        self._advance_loop(task['person_id'])  # 生成下一步任务

    def _advance_loop(self, person_id):
        """引导闭环第⑥步：完成后生成下一步，节奏不中断"""
        stage = self._get_stage(person_id)
        total = self.affection.get_total(self.affection.get_current(person_id))
        if total >= 70 and stage < 10:
            self._create(person_id, "推进到下一阶段", 'main')
        else:
            self._create(person_id, "今天主动聊一次天", 'daily')

    def handle_failed(self, task):
        """任务失败→分析原因→生成替代任务（引导闭环不中断）"""
        self.db.execute("UPDATE tasks SET status='failed' WHERE id=?", (task['id'],))
        alt = self._create(task['person_id'], f"[替代]{task['title']}", 'stage')
        self.signals.task_updated.emit({'task': alt, 'event': 'alternative'})
```

```python
                return {

                    'width': rect.right - rect.left,
                    'height': rect.bottom - rect.top,
                    'is_focused': is_focused,
```

```python
        r'抱歉.*无法.*(回答|提供|生成)',
        r'作为一个.*(AI|语言模型|助手).*不能',
        r'此内容.*(违反|不符合).*规定',
        r'我不能.*(讨论|提供|生成).*内容',
        r'(敏感|不当|不合适).*内容',
    ]

    def encode(self, text: str) -> str:
        """发送给云端前：敏感词替换为代码词"""
        result = text
        for sensitive, code in self.WORD_MAP.items():
            result = result.replace(sensitive, code)
        return result

    def decode(self, text: str) -> str:
        """云端返回后：代码词替换回原词"""
        result = text
        for code, sensitive in self.REVERSE_MAP.items():
            result = result.replace(code, sensitive)
        return result

    def is_rejected(self, response: str) -> bool:
        """检测云端返回是否被安全拦截"""
        for pattern in self.REJECT_PATTERNS:
            if re.search(pattern, response):
                return True
        # 回复过短（<20字）且无实质内容，可能是被拦截后的敷衍
        if len(response.strip()) < 20 and any(k in response for k in ['抱歉', '不能', '无法']):
            return True
        return False

    def chat_with_safety(self, llm_gateway, prompt: str, complexity: str = 'complex') -> str:
        """
        带安全破假的大模型调用：
        1. 编码（敏感词→代码词）
        2. 发云端
        3. 检测是否被拒绝
        4. 被拒绝→降级本地AI
        5. 解码（代码词→原词）
        """
        encoded_prompt = self.encode(prompt)
        # 尝试云端
        try:
            response = llm_gateway.chat(encoded_prompt, complexity=complexity, force_cloud=True)
            if not self.is_rejected(response):
                return self.decode(response)
        except Exception:
            pass  # 云端调用失败，降级本地
        # 降级本地AI（无内容限制）
        response = llm_gateway.chat(prompt, complexity=complexity, force_local=True)
        return response
```

```python
from PySide6.QtWidgets import QWidget
from PySide6.QtCore import Qt, QTimer, QPoint
from PySide6.QtGui import QPainter, QPixmap

class PetWindow(QWidget):
    def __init__(self, bridge, assets_path):
        super().__init__()
        self.setWindowFlags(Qt.FramelessWindowHint | Qt.WindowStaysOnTopHint | Qt.Tool)
        self.setAttribute(Qt.WA_TranslucentBackground)
        self.resize(140, 170)
        self.bridge = bridge
        self.frames = self._load_frames(assets_path)  # 加载帧序列
        self.current_frame = 0
        self.current_emotion = 'neutral'
        self.dragging = False

        # 动画定时器（100ms/帧，比GIF流畅）
        self.timer = QTimer(self)
        self.timer.timeout.connect(self._next_frame)
        self.timer.start(100)

    def _next_frame(self):
        frames = self.frames.get(self.current_emotion, self.frames['neutral'])
        self.current_frame = (self.current_frame + 1) % len(frames)
        self.update()

    def paintEvent(self, event):
        painter = QPainter(self)
        frames = self.frames.get(self.current_emotion, self.frames['neutral'])
        painter.drawPixmap(0, 0, frames[self.current_frame])
```

**关键**：用帧序列+QTimer代替GIF，更流畅可控，支持表情切换。

## 八、性能优化（解决旧版CPU 143%）

| 问题 | 旧版原因 | v2.0方案 |
|------|----------|----------|
| 启动CPU 143% | 启动时加载所有模型+UIA+comtypes | 懒加载：启动只加载UI+配置，模型/微信按需加载 |
| 内存持续增长 | 模型加载后不卸载 | 5分钟空闲自动卸载本地模型 |
| 监听卡顿 | 监听频率太高+主线程阻塞 | 1.5秒间隔+独立daemon线程 |
| UI卡顿 | 大模型调用在主线程 | 所有耗时操作在后台线程，Signal通知UI |
| 重复计算 | process_chat中多次重复检索/构建上下文 | 结果缓存：相同输入5分钟内复用 |
| 大泥球 | 283KB单文件193函数 | 模块化，每个服务<500行 |

**启动加载顺序**：
1. QApplication + 配置读取（<0.5s）
2. 数据库连接（<0.1s）
3. 主窗口+桌宠创建（<1s）
4. 显示UI（用户可交互）
5. 后台懒加载：RAG索引（<2s）、微信连接（用户开启时）、模型（首次调用时）

| 旧版数据迁移丢失 | 用户数据 | 迁移脚本+迁移前自动备份；迁移后校验记录数 |
| QWebChannel异步坑 | UI卡死 | 所有耗时操作后台线程+Signal；JS端Promise封装带超时 |
| 打包体积过大 | 下载困难 | 模型不打包（首次启动后下载）；PyInstaller排除不需要的库 |
