## 二、环境与关键坑（已解决）

- Python **3.14.7**（很新），8GB 内存，显卡 NVIDIA GTX 1050 4GB。
- 装包走华为云 PyPI 镜像；HuggingFace 直连超时 → 已默认走 `https://hf-mirror.com` 并禁用 hf-xet（xet 对镜像报 401）。
- **faster-whisper 1.2.1 自带的音频解码和本机 av19 不兼容**（`av.open(metadata_errors=...)` 报错）。解法：自己把 PCM/WAV 直接转成 float32 numpy 喂给 whisper（whisper 支持 ndarray 输入），彻底绕过 PyAV。
- **内存只有 8G**：本地大模型（1.1G GGUF）+ whisper（~150M）同时驻留会吃紧；桥接里模型都是**懒加载**，不用不占内存。

## 三、怎么启动、怎么用

### 1. 启动语音后端（Python 桥接）
```powershell
cd <工程根>
scripts\start_voice_bridge.bat
```
或手动：`.\.venv\Scripts\python.exe scripts\pet_voice_bridge.py`

启动日志会打一行：
```
启动：llm=local_llama tts=edge stt=True
WS 服务已启动: ws://127.0.0.1:9876
HTTP 静态服务已启动: http://127.0.0.1:9877/
```
健康检查：浏览器开 `http://127.0.0.1:9877/_health` → `{"ok":true,"llm":"local_llama","tts":"edge","stt":true}`。

### 2. 启动桌宠（Electron）
```powershell
cd <工程根>\desktop-pet-electron
npm start
```
（主进程已加麦克风权限放行，无需手动授权。）

### 3. 对话流程（真语音）
1. 双击角色进沉浸式模式，点中间蓝色语音球 → 球变红脉动 = **正在听你说话**。
2. 直接对着麦克风说（如"老婆我今天好累"），说完**再点一下语音球**停止。
3. 球变紫转圈 = 本地 Whisper 转写 + 本地大模型思考（首次约 20~30 秒）。
4. 立绘开口说话，球橙光，口型随音频动；字幕条显示识别到的原话和她的回复。

> 点麦克风失败会自动退回 `prompt()` 键盘输入兜底，不会卡死。

## 四、各模块怎么接的

### 1) 真麦克风 STT
- 新增 `services/stt_service.py`：faster-whisper 懒加载、CPU int8、中文。`transcribe_pcm16(bytes)` 直接吃 16k PCM16。
- 桌宠 `renderer/js/voice-input.js` **重写**：点球 → `getUserMedia` → Web Audio 取 PCM → 线性重采样 16k → Int16 → 通过 `wsClient.sendBinary()` 流式发给后端；再点一次发 `stop_recording`。
- 桥接收到二进制帧按连接累积，`stop_recording` 时丢线程池跑 Whisper，回推 `asr_result` 给桌宠气泡。

### 2) 真 LLM（多 provider 自动选路）
- 新增 `services/llm_providers.py`，优先级 **local_llama → ollama → cloud → 模板**：
  - `local_llama`：llama-cpp-python 直加载本地 GGUF（**当前默认，完全离线**）。
  - `ollama`：本机 Ollama 的 OpenAI 兼容接口（备用）。
  - `cloud`：配了 `OPENAI_API_KEY` 就走任意 OpenAI 兼容云。
- 用环境变量 `LOVEAI_LLM_BACKEND=local_llama|ollama|cloud|template` 可强制指定。

### 3) 语音克隆（P1）
- 新增 `services/tts_providers.py`：`edge-tts`（默认）+ `CloneTTSProvider`（对接外置克隆 HTTP 服务）。
- 配法（环境变量）：
  ```
  LOVEAI_TTS_BACKEND=clone
  LOVEAI_CLONE_URL=http://127.0.0.1:9880     # GPT-SoVITS api_v2 / CosyVoice 推理服务
  LOVEAI_CLONE_TEXT=<参考音频里说的话>
  LOVEAI_CLONE_AUDIO=<10~30秒干净人声wav路径>
  ```
  服务可达就自动用克隆音色，不可达自动回落 edge-tts。
- **为什么不在本机装 GPT-SoVITS/CosyVoice**：它们要 Python 3.10~3.12 + torch + 数 G 模型，本项目是 py3.14，强装会污染整环境且编译极慢；用 HTTP 解耦，克隆服务放独立环境/另一台机器都行。

### 4) 本地大模型（P2）
- `pip install llama-cpp-python` 直接拿到 win 预编译 wheel，**没编译**。
- 模型：`models_local/qwen2.5-1.5b-instruct-q4_k_m.gguf`（已下载，1.04GB）。
- 另附 `models_local/Modelfile.ollama`，想走 Ollama 路线：`ollama create loveai-qwen -f models_local/Modelfile.ollama`。

### 5) 数字人（P3）
- 新增 `services/digital_human.py`：`RemoteDigitalHuman`（对接外置 Wav2Lip/MuseTalk/SadTalker fastapi 服务）+ `Degraded2D`。
- 探测不到外置服务时自动降级，桌宠继续用 2D 立绘口型。开关环境变量 `LOVEAI_DH_ENABLE`。
- 不建议本机硬装：8G 内存 + GTX1050 4G，实时数字人跑不动；现在的振幅驱动口型已是轻量替代。

## 五、WS 协议（本轮新增）

**端口**：WS=9876，HTTP=9877（MP3 静态）

下行：`hello / speech_state / ai_thinking / asr_result / ai_speak(text,audio_url)`
上行：
| event | 字段 | 说明 |
|---|---|---|
| `start_recording` | — | 开始录真麦克风 |
| **二进制帧** | bytes(PCM16@16k) | 流式音频 |
| `stop_recording` | — | 停止并转写 |
| `user_text` | text | 键盘输入（兜底） |

## 七、诚实说明（限制）

1. **本地大模型慢**：纯 CPU 跑 1.5B，首句加载 ~4 秒、生成 ~25 秒/句。要快就配 `OPENAI_API_KEY` 走云，或把 `LOVEAI_LLM_BACKEND` 切到 ollama（有 CUDA 时会自动用 1050）。
2. **语音克隆/数字人是接口不是真模型**：受限于 py3.14 + 8G 内存，没在本机装 GPT-SoVITS/CosyVoice/Wav2Lip；但接口、配置、降级都做完了，备好模型一键切。
3. STT 模型是 `base`（约 145MB，已下好）；想要更准可设 `LOVEAI_STT_MODEL=small`（更慢更准）。
4. 对话历史仍在内存，重启清空；MP3 缓存暂未自动清理（不影响功能）。
