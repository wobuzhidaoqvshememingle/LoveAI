## 三、已确认死路 / 强不推荐 / 本期不实现

1. **纯 ReadProcessMemory 内存扫描在微信 ≥4.1.10 彻底失效（P2 内子路径，已确认死路）**：
   密钥不常驻、passphrase 模式、内存中 `x'hex'` 串被移除；仅 DLL 注入 + Hook（P9 路线）可取。
   依据：`docs\wechat_methods_report.md`（微信 4.1.15.13）。**P2 整体仅对旧版有效，并真实探测版本。**
2. **A5 模拟器登录（`android\a5_emulator.py:45`，high/默认关）——强不推荐**：
   2026 有明确**封号、人工核实不解封**实锤；技术路径保留，仅检测+引导，绝不自动登录，需显式确认。
3. **iOS iTunes 备份解析（`ios_reserve.py:11`）——本期不实现**，仅预留接口。
