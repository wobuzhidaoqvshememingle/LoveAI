# 微信采集通道 · 随安装器分发清单 v1.0

> 面向后续统一封包；本期只落地采集体系，不执行封包。平台：Windows x64；运行时 Python 3.14。
> 原则：本地优先、默认不联网上传；高风险工具默认不启用。

## 一、必发 · 核心运行时（开箱即用的零/低风险通道）

| 类别 | 内容 | 用途（通道） | 形态 |
|---|---|---|---|
| Python | Python 3.14 运行时 | 全部 | 嵌入式/安装器内置 |
| 解密/验密 | `cryptography` | P1/P3/P4/P5/A4 等 | wheel（venv 已装 50） |
| 加密库直连 | `sqlcipher3` | P1 验密/导出、T2 已解密库 | wheel（venv 已装 0.6.3，含原生 dll） |
| 本地 OCR | `rapidocr-onnxruntime` + `onnxruntime` | T4/P6/P7/A2 | wheel，**包内自带检测/识别/分类 ONNX 模型**（数十 MB，需一并封入） |
| 图像/拼接 | `opencv-python`、`numpy`、`Pillow` | P7 拼接、截图处理 | wheel（venv 已装） |
| 窗口/进程 | `pywin32`、`pywinauto`、`psutil`、`Pymem`、`pyperclip` | P6 抓窗、P2/P3 进程与内存、取证 | wheel（venv 已装） |
| 数据/ORM | `SQLAlchemy` | 统一入库 `store.py` | wheel（venv 已装） |
| ADB | `tools\platform-tools\`（`adb.exe` + `AdbWinApi.dll` + `AdbWinUsbApi.dll`） | A1/A2/A6 | 随包目录（已确认存在） |
| 取证脚本 | `tools\wechat_forensics\dump_wechat.py` | P3 生成 MiniDump | 随包脚本（运行需管理员+SeDebug） |
| 采集包 | `services\collectors\` 全部代码 + `fixtures\` | 全部通道 | 随包目录 |

## 三、不分发 · 仅引导（外部/高风险，条件满足由用户自行准备）

| 内容 | 通道 | 原因 |
|---|---|---|
| Hibr2DMD / Volatility 3（hiberfil→raw 转换器） | P4 | 体积/许可各异；适配器真实探测 PATH 与 `tools\`，缺失即给引导 |
| Frida / frida-tools | P9 | 注入框架，研究向；不默认安装，`pip install frida frida-tools` |
| 旧版微信安装包(<4.1.10) | P2/P10 | 由用户自备；降级/旧版解密场景 |
| 模拟器环境 | A5 | **2026 封号/不解封实锤，不推荐、不分发、不自动登录** |
| iTunes/访达备份及口令 | iOS | 本期仅预留接口，未来再支持 |

## 四、封包注意

1. **OCR 模型别漏**：rapidocr 的 ONNX 模型在 site-packages 内，封包需随 wheel 一起保留，否则 T4/P6/A2 离线失效。
2. **原生 dll 依赖**：sqlcipher3、onnxruntime、opencv、pywin32 均含编译产物，需按 win-x64 完整保留；建议以当前 venv 快照为基准冻结依赖版本。
3. **ADB/scrcpy 为多文件**：adb 必须连同两个 DLL，否则无法启动。
4. **高风险合规**：wx_key、Frida、模拟器、蓝屏/休眠触发相关项默认禁用并在 UI 强提示；发送功能永远手动。
5. **体积预估重点**：OCR(onnxruntime+模型) 与可选视觉模型占大头；核心零风险通道（P1/T1/T2/T3）体积很小。
