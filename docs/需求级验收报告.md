### 1.4 三档人设横向观察（如实记录）

- **生成是真的，不是模板**：18 个 LLM 调用全部返回非空、结构各异、带具体措辞的中文，无一条命中 `rules`/`stat` 兜底。
- **但 1.5B 的人设区分度不足**：三档人设的输出在情绪标签上高频扎堆「焦虑/neutral」，NPD 应有的「优越感/贬低/忽冷忽热」与 BPD 应有的「非黑即白/质问/被抛弃恐慌」没有稳定体现出来；多轮里 NPD 与 BPD 的回复风格趋同于「温和询问+建议继续沟通」。
- **存在视角混淆**：`predict_reaction` 本应模拟「她」的内心，但多处 `inner_thought` 写成了用户视角（如安全型 T2「对方今天项目被甲方挑错，我应该理解她的情绪」）；`possible_replies` 偶尔冒出用户口吻的反问（如 NPD T2「你为什么不回我？」）。这是小模型角色扮演能力不足的真实表现。
- **概率数字有幻觉**：如「答应概率 90%/85%/70%」是模型凭空给出的精确数字，无真实统计支撑，不应被前端当作可信数值。

## 3. 双路线验证（同一冲突场景：5 天不回后突然回"嗯"）

场景：NPD 回避型女生，用户追问后沉默 5 天，今天只回了一个"嗯"。

### 3.1 制服/反制路线（复用 manipulation_coach）

`build_counter_manipulation()` 真实模块输出（**纯规则，0.0s，非 LLM**）：

- 命中模式：`gaslighting`（煤气灯式贬低）、`money_control`（金钱/条件式控制）
- 当前状态：情绪「冷漠/回避」、依恋激活「回避激活（此刻在疏离）」
- 策略风格：**温水煮青蛙（渐进式）**——"突然断供会直接跑，需渐进式"
- 核心反制步骤（节选原文）：
  > 1. 渐进式减量：不要从 100% 立刻降到 0%，而是 100→70→50→30 阶梯减量……
  > 2. 条件交换替代无条件给予："给可以，但你也要做点什么"……
  > 3. 可得性波动（间歇性强化反用）：有时满足、有时延迟、有时拒绝……
  > 6. 引导对方投入（反制的核心目标）：用富兰克林效应请对方帮小忙……
- 反馈分支：对方理解并配合→正强化；一提要求不被满足就翻脸→纯索取，刚猛止损一次；不冷不热→维持档位观察一周。

再用**真实 LLM（last_layer=l2，4.38s）**把上述规则渲染成可发话术：
> 现在就可以发的一句开场白："嗯"。
> 接下来 3 天动作：1. 每天晚上 7 点前发一条温馨私信表达关心；2. 用对方喜欢的表达方式增加连接；3. 保持开放接受反馈。
> 对方不冷不热时：保持沉默、给空间，不主动加码也不撤退。

> **如实记录（能力缺陷）**：LLM 这一步**没有忠实执行规则计划**——manipulation_coach 明明要求「渐进减量、不主动加码、不每天发温暖私信」，LLM 却生成了「每天晚上 7 点前发温馨私信」，方向与反制路线自相矛盾。规则模块本身是对的，但小模型把规则落地成话术时会跑题。

> 2. 提出开放性问题："我注意到我们最近交流有些少，有没有什么特别想和我说的吗？"
> 3. 给予空间：如果她没回，不要强求。
> 5. 创造机会：她开始回复后，选轻松环境计划见面。

### 不通过项 / 能力缺口（如实记录，禁止假绿）

2. ❌ **视角混淆**：`predict_reaction` 多处把「她」的内心写成用户视角，`possible_replies` 偶发用户口吻，角色扮演的第一人称一致性不足。
3. ❌ **LLM 落地规则时会跑题**：反制路线的 LLM 话术渲染与 manipulation_coach 的「渐进减量/不主动加码」直接矛盾（生成了「每天发温暖私信」），规则→话术的这一跳在 1.5B 上不可靠。
4. ❌ **consult_engine 输出偏通用鸡汤**：修复路线回答（耐心等待/给空间/慢慢来）没有充分结合 NPD 画像给出针对性策略，深度不足；精确概率数字（90%/85%）属幻觉，不可被业务采信。

### 总评
**"链路真实、生成自由、离线可靠"这一需求级目标已达成；但"1.5B 小模型能稳定扮演差异化人格并忠实执行策略"这一质量目标未达成。** 当前架构（L2 Ollama 生成 + 规则模块兜底策略骨架）方向正确：规则层（manipulation_coach / strategy_advisor）质量高，短板在 1.5B 生成侧的人设保真与指令遵循。建议后续：(a) 把规则模块输出作为强约束注入 LLM prompt 并要求逐条映射，减少跑题；(b) 对人设扮演场景尝试更大本地模型或 few-shot 示例；(c) 前端不要直接采信模型自报的 confidence/概率数字。
