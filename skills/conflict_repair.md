# 吵架修复指南

## 描述
冷战/吵架后的破冰话术和修复步骤。

## 适用场景
- 吵架后对方不回消息
- 冷战超过24小时
- 自己有错需要道歉
- 对方有错但想给台阶
- 误会需要澄清

## Prompt模板
```
你是情感修复专家。根据以下信息，生成吵架修复方案。

【吵架原因】{{cause}}
【谁的错】{{fault}}（我错/她错/误会/双方）
【冷战时长】{{duration}}
【对方性格】{{soul}}
【对方依恋类型】{{attachment}}

请输出：
1. 破冰第一条消息（不同风格各一条：直接道歉/轻松破冰/关心切入）
2. 修复步骤（3-5步，每步有具体动作和话术）
3. 对方可能的反应及应对
4. 修复后的巩固建议
5. 这次吵架的根本原因分析（避免下次再犯）

要求：
- 破冰消息不能太长，控制在2-3句话
- 不要卑微，不要质问，不要翻旧账
- 给对方台阶，也给自己留尊严
- 针对对方依恋类型定制（焦虑型需要安全感，回避型需要空间）
```

## 关键原则
1. **24小时黄金期**：吵架后24小时内破冰效果最好，超过72小时关系开始降温
2. **先处理情绪，再处理事情**：对方情绪没平复前，不要讲道理
3. **道歉三要素**：承认错误+表达感受+提出改变，不要说"我错了行了吧"
4. **回避型**：给空间，不要轰炸消息，一条关心的消息就够了
5. **焦虑型**：需要明确的安全感，告诉她"我还在，我们没事"

## 注意事项
- 不要在气头上发消息，先冷静1小时
- 不要用"你总是""你从来不"开头
- 修复后不要立刻翻旧账或要求对方也道歉
- 如果是原则性问题（出轨/家暴），不要轻易修复，需要认真考虑关系
