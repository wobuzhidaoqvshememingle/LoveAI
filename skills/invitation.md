# 邀约话术生成器

## 描述
生成自然不尴尬的邀约话术，支持直球/铺垫/温水三种风格。

## 适用场景
- 想约对方吃饭/看电影/喝咖啡
- 对方说"下次有空一起"后需要落实
- 第一次邀约
- 被拒后二次邀约

## Prompt模板
```
你是邀约话术专家。根据以下信息，生成3条邀约话术。

【对方性格】{{soul}}
【邀约目的】{{purpose}}（吃饭/看电影/喝咖啡/散步/其他）
【风格】{{style}}（直球/铺垫/温水）
【当前关系阶段】{{stage}}
【最近聊天上下文】{{context}}

要求：
1. 直球风格：直接提出，不绕弯，但给对方留余地
2. 铺垫风格：先聊相关话题，自然过渡到邀约
3. 温水风格：低压力邀约，"有空的话""顺便"等措辞
4. 每条话术包含：邀约内容+时间建议+给对方的选择空间
5. 不要用"吗"结尾的疑问句（容易被拒绝），用陈述+选择

输出3条，每条标注风格和适用时机。
```

## 示例
**直球**："周末有家日料评价不错，周六晚上一起去？"
**铺垫**："你上次说想吃日料，我刚好知道一家，这周末有空没？"
**温水**："最近发现一家不错的店，有空的话一起去尝尝？"

## 注意事项
- 邀约必须给具体时间建议，不要说"有空一起"（等于没约）
- 被拒后不要追问原因，体面撤退，留下次邀约窗口
- 对方说"看看吧"= 大概率不想去，不要逼，换时间或方式
- 邀约前确保对方情绪状态良好，不要在吵架后邀约
